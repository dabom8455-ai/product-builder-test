## 0. 한 줄 결론

**도입하되, 가치는 '도구'가 아니라 '상류'에 있다.**
이 도구는 누구나 무료로 쓰는 생산 도구라서 해자(moat)가 아니다. 이걸로 **콘텐츠 생산 원가를 0에 가깝게 낮추고**, 남는 시간과 돈을 **고객 접점·브랜드·재등록률**(상류)에 넣는 게 머니댐 설계다.

| 판단 | 내용 |
|---|---|
| 도입 여부 | O. 웹 버전으로 2주 시범 → 효과 확인 후 데스크톱·자동화 |
| 기존 유료 구독 해지 | 보류. 시범 기간 결과물 품질·크레딧 비용 비교 후 결정 |
| 외부 수익화 | 학원 내부 적용으로 사례(포트폴리오) 3개 확보 후 |
| 우선순위 | ① 학원 홍보 자동화 → ② 학부모 리텐션 콘텐츠 → ③ 원장 대상 대행·교육 |

## 1. 도구 팩트 체크 (가이드 주장 vs 실제)

| 항목 | 가이드/홍보 문구 | 확인된 사실 | 의미 |
|---|---|---|---|
| 정체 | 무료 AI 영상 스튜디오 | MIT 오픈소스 앱(Next.js/Electron). 실제 생성은 대부분 **Muapi.ai API** 경유 | 앱은 무료, **클라우드 생성은 Muapi 크레딧** |
| 모델 수 | 200개+ | 페이지 내에서도 200+/400+/600+ 표기 혼재 | 숫자보다 "주요 모델 몇 개를 한 곳에서" 가 핵심 |
| 주요 모델 | — | Flux, Nano Banana 2, Midjourney, Kling, Sora, Veo, Seedream 5.0, Seedance 2.0, Hailuo, Wan 2.2, Runway, Ideogram 등 | 모델마다 따로 구독하던 구조를 크레딧 1개로 통합 |
| 스튜디오 | Image / Video / Cinema / Lip Sync | + Audio, AI Clipping, Marketing, Workflow, Agent 스튜디오 | 마케팅·워크플로까지 확장 중 |
| 로컬 실행 | 키 없이 내 PC에서 | 이미지(sd.cpp)는 맥/윈도우 가능. **영상(Wan2GP)은 NVIDIA/AMD GPU 필수, 애플실리콘 불가** | 맥 사용자는 영상 = 클라우드 크레딧 |
| 인기 | — | GitHub 스타 약 3.1만 | 프로젝트 지속성은 양호한 편 |
| 보안 | 공식 릴리스만 받으라 | 미서명 설치본(맥 Gatekeeper·윈도우 SmartScreen 경고 우회 필요), API 키는 브라우저 localStorage 저장 | 업무용 PC에서는 **웹 버전 우선** |
| 콘텐츠 필터 | "필터 없음" 표방 | 클라우드는 Muapi 정책 적용 | 학원 브랜드에선 오히려 **자체 가이드라인 필수** |

**가이드 자체의 수익 구조**: 이메일 수집 → 30일 AI 챌린지(유료 강좌) 판매 + 광고 협업. 즉 "무료 도구 가이드"는 **리드 마그넷**이다. 이 구조 자체가 우리가 베낄 수 있는 모델이다(5장 참고).

## 2. 머니댐 구조 안에서의 위치

```
[상류: 확보해야 할 것]          [수로: 이 도구가 하는 일]        [댐: 쌓이는 것]
 지역 학부모 신뢰·검색 노출   →   이미지/영상 대량·저비용 생산   →   신규 문의 ↑
 원생 데이터(진도·발표회)     →   주간 자동 콘텐츠 파이프라인    →   재등록률 ↑ / 이탈 ↓
 원장 네트워크                →   검증된 템플릿·프롬프트 자산     →   대행·교육 반복 매출
```

- 도구는 **교체 가능한 펌프**. 언제든 더 싼 펌프로 바꿀 수 있게, 자산은 도구가 아니라 **프롬프트 템플릿·브랜드 스타일 가이드·결과물 아카이브**로 쌓는다.
- 생성형 미디어 원가가 0으로 수렴 → 콘텐츠는 공급 과잉 → 희소한 것은 **실제 원생 성과, 원장 얼굴·목소리, 지역 신뢰**. AI 이미지는 '포장', 실제 성과는 '내용물'.

## 3. 적용 기획 ① — 도현피아노 홍보 자동화 (즉시, 0~4주)

기존 `weekly-publish-prep`(블로그 → 스레드) 흐름에 **비주얼 단계**를 붙인다.

| 산출물 | 주기 | 스튜디오 / 설정 | 비고 |
|---|---|---|---|
| 블로그 썸네일 1장 | 주 1 | Image Studio, 브랜드 색·폰트 고정 프롬프트 | 글 제목 텍스트는 Canva/직접 합성(AI 한글 텍스트 품질 불안정) |
| 스레드·인스타 카드 3~5장 | 주 1 | Image Studio | 블로그 핵심 문장 1개 = 카드 1장 |
| 15초 릴스/쇼츠 1개 | 주 1 | 이미지 → Video Studio (image-to-video) | 피아노 건반·악보·햇살 드는 연습실 등 **사물·공간 중심** |
| 시즌 홍보 영상 | 분기 1 | Cinema Studio (제품/공간 24mm·f/11, 감성 35mm·f/1.4) | 발표회, 방학 특강, 신학기 모집 |
| 원장 인사 영상 | 분기 1 | Lip Sync Studio — **원장 본인 사진·본인 목소리만** | 원생 얼굴 사용 금지 |

**주간 파이프라인 (자동화 목표 형태)**

```
월: 블로그 주제 선정 → Claude가 블로그·스레드 초안 (기존 스킬)
   → Claude가 각 글에서 비주얼 프롬프트 5개 추출 (브랜드 스타일 고정 문구 포함)
   → muapi-cli로 이미지 5장 + 15초 영상 1개 생성 → /output/YYYY-WW/ 저장
화: 원장 검수(3분) → 게시
```

자동화 준비물: Node.js, `npm install -g muapi-cli`, `muapi auth configure`(키는 저장소·채팅에 절대 노출 금지), Generative-Media-Skills.

**KPI (4주)**
- 콘텐츠 제작 시간: 주 X시간 → 50% 이하
- 블로그 썸네일 교체 후 조회수/클릭률 변화
- 플레이스·블로그 경유 상담 문의 건수 (월 기준선 대비)

## 4. 적용 기획 ② — 학부모 리텐션 콘텐츠 (4~8주)

신규 모집보다 **재등록률 1%p**가 더 싼 매출이다. 학원의 상류 = 기존 학부모.

| 콘텐츠 | 방식 | 효과 |
|---|---|---|
| "이번 달 곡 이야기" 카드 | 연습곡의 작곡가·배경을 그림책 스타일 이미지 2~3장으로 | 아이 연습 동기, 학부모 단톡 공유 |
| 진도 달성 축하 카드 | 레벨 달성 시 템플릿 이미지 + 아이 이름(텍스트 합성) | 성취 가시화 → 이탈 방지 |
| 발표회 포스터·초대장 | Image + Cinema Studio | 인쇄비·디자인 외주비 절감 |
| 음악이론 30초 애니 | Video Studio로 개념 시각화(박자, 음계) | 수업 보조 자료 |

- 결석 원비 계산기(`index.html`)처럼 **학원 운영 도구 + 콘텐츠**를 묶으면 학부모 경험 전체가 브랜드가 된다.

## 5. 적용 기획 ③ — 외부 수익화 (8주~, 사례 확보 후)

| 모델 | 대상 | 가격 가설 | 원가 | 조건 |
|---|---|---|---|---|
| A. 학원 홍보 콘텐츠 대행 | 지역 음악·예체능 학원 원장 | 월 15~30만원 (주 1회 썸네일·카드·릴스 세트) | 크레딧 + 검수 시간 | 자기 학원 사례 3개 필요 |
| B. 템플릿·프롬프트 팩 판매 | 학원 원장 | 1~5만원 단건 | 0 (한 번 만들면 반복 판매) | 디지털 자산 = 진짜 머니댐 |
| C. 원장 대상 AI 활용 강의 | 원장 커뮤니티·카페 | 회당 소액 + 사후 컨설팅 | 시간 | lazyowen 모델(무료 가이드 → 이메일 → 유료 과정) 그대로 적용 |
| D. 화이트라벨 | — | Muapi 화이트라벨 월 $49~ | 고정비 | **후순위**. 고객 10곳 이상일 때만 검토 |

**순서가 중요**: C(무료 가이드 배포)로 리드를 모으고 → B로 첫 결제 → A로 반복 매출. 원장 네트워크가 상류다.

## 6. 비용·리스크 관리

**비용 원칙**
- Muapi 크레딧 단가는 공식 페이지에 명시가 불충분 → 시범 기간 **월 예산 상한(예: 5만원)** 정하고 결과물 1개당 원가 기록.
- 비교 대상: 현재 쓰는 유료 구독(Canva, 영상 AI 등) 월 합계. 시범 후 "같은 품질에 더 싸면" 해지.
- 로컬 영상 생성을 위해 GPU PC를 사는 건 **비추천**. 주 1개 수준 물량에선 클라우드 크레딧이 훨씬 싸다(설비 투자 회수 불가).

**리스크 체크리스트**
- [ ] **아동 이미지 금지**: 실제 원생 사진을 모델에 올리거나 실존 아동처럼 보이는 이미지 생성 금지. 인물은 원장 본인 또는 손·실루엣만.
- [ ] **AI 생성 표시**: 한국 AI기본법(2026년 시행)의 생성형 AI 결과물 고지 취지에 맞춰 게시물에 "AI 생성 이미지" 표기 습관화.
- [ ] **상업 이용 조건**: 모델별 라이선스 상이. 홍보물에 쓰는 모델은 상업 이용 허용 여부 확인 후 고정.
- [ ] **보안**: 설치본은 GitHub 공식 릴리스에서만. API 키는 저장소·채팅·스크린샷에 노출 금지. 업무 PC는 웹 버전 우선.
- [ ] **의존도**: 프롬프트·스타일 가이드는 이 저장소에 텍스트로 보관 → 도구가 사라져도 다른 서비스로 이전 가능.
