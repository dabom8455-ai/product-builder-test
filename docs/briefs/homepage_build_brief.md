# [작업 지시서] 도현피아노 공식 홈페이지 구축 — 마케팅팀

> 발신: 클부장(총괄) · 수신: ②마케팅팀 · 상태: 🔨 진행(시안 승인 대기)
> 관련 팀 문서: `docs/teams/team2_marketing.md` (2-3 리드·판매 자동화 / 판매 페이지)

---

## 1. 목적
도현피아노 학원의 **공식 홈페이지**를 만든다. 두 가지 역할을 동시에 한다.
- **B2C:** 학부모가 보고 신뢰해 → 무료 상담 신청(리드)으로 전환
- **정체성:** "AI 자동화로 운영, 사람은 교육에 집중"이라는 우리만의 차별점을 전면에 내세움

## 2. 완성된 산출물 (시안)
클부장이 디자인 초안을 제작 완료. 마케팅팀은 이 시안을 **실제 홈페이지로 구현**한다.
- 디자인 시안(메인 랜딩 + 회사 조직도): **Claude Design 캔버스 링크는 대표 보고 메시지 참조**
- 시안 원본 파일: `design/homepage/` (`Main.dc.html`, `OrgChart.dc.html`, `canvas.json`)

## 3. 디자인 스펙 (시안 기준)
- **팔레트:** 아이보리 `#F4EEE1` · 딥그린 `#1E4A3C` / `#163A2F` · 골드 `#C4A24B` · 본문 `#23261F`
- **폰트:** 제목 Noto Serif KR / 본문 Noto Sans KR
- **톤:** 따뜻하고 신뢰감 있는 교육 브랜드. 과장 없는 정갈함.

## 4. 메인 페이지 섹션 (순서 고정)
1. **히어로** — "피아노에 집중합니다. 나머지는 AI가 합니다." + 무료 상담 CTA + 위치 태그(용인·모현읍)
2. **학원 소개** — "사람은 교육에, 시스템은 운영에" + 3대 가치(맞춤지도/투명한 진도/끊김없는 소통)
3. **커리큘럼** — 유아 / 기초·취미 / 심화 / 입시·전공 4단계
4. **AI 자동화 강점(차별점)** — 상담 자동응대 / 출결·진도 자동관리 / 학부모 소통 자동화
5. **수강 안내** — 취미 / 심화 / 입시 3개 카드 (수강료는 상담 후 안내 구조)
6. **상담 문의 CTA** — 전화·주소·카카오톡 상담 버튼
7. **푸터**

## 5. 대표님이 채워야 할 실제 정보 ([대괄호] 자리)
- [ ] 전화번호
- [ ] 학원 상세주소 (모현읍 이후)
- [ ] 취미/심화 과정 월 수강료, 주 횟수·회당 시간
- [ ] 카카오톡 채널(오픈채팅/채널 ID) 링크
- [ ] (선택) 실제 학원 사진 3~5장 — 히어로·소개 섹션 교체용

## 6. 마케팅팀 실행 지시 (물길 우선)
1. **[L0] 구축 도구 결정** — 노코드(아임웹/윅스/네이버 등) vs 자체 개발. 초안 단계는 **노코드 권장**(빠른 출시·수정).
2. **[L0] 시안 → 실제 페이지 이식** — 위 섹션·팔레트·카피 그대로 옮긴다.
3. **[L0] 상담 신청 폼 연결** — CTA 버튼 → 리드 수집 폼(이름·연락처·아이 나이). 이 리드는 ①학원운영팀 상담 자동응대로 연결(추후).
4. **[L1] 전환 추적** — 방문 수·상담 신청 수를 볼 수 있게 최소한의 지표 세팅.

## 7. 완료 기준 (Definition of Done)
- [ ] 실제 URL로 접속 가능한 홈페이지 1개 (모바일에서도 정상)
- [ ] 무료 상담 신청 폼이 실제로 리드를 수집함
- [ ] 대표님 실제 정보([대괄호]) 모두 반영
- [ ] 첫 방문자 피드백 3명 이상 수집 → 수정 반영

## 8. 우선순위 판단 (클부장)
- 영향 **큼** (첫 고객 접점 + 정체성 노출) / 시급성 **중** → **계획 편성 후 빠른 실행**.
- 병렬 가능: ①학원운영팀 상담 자동응대 준비와 함께 진행하면, 폼 리드가 곧바로 자동응대로 이어지는 그림이 완성됨.
