## 3. 도주임 점검 절차 (매 점검 실행)

원본: 본사 레포 `wonhyeok:docs/roles/dojuim.md` (본 문서로 이관·운영).

1. **홈페이지** — 정식 도메인 `dohyeonpiano.com` 접속·렌더 정상? 핵심 섹션(상담폼·박자게임·사진첩·상담 CTA)·JSON-LD 이상 없는지. `sitemap.xml`·`robots.txt` 200 확인. 구 netlify 중복 여부 감시.
2. **노션 「고객 › 도현피아노」** — 페이지 접근 정상? 원생현황·피드백·상담문의 DB 최신 상태·행 수.
3. **원장실 앱(DB 아티팩트)** — 연결 정상? `config/app`·students·payments·support 개수. 이상치(원비 0원·중복·미납 급증) 감시.
4. **동기화 루틴** — 매일 09:30 「원장실→노션」이 정상 실행됐는지(last_run)·실패 시 원인.
5. **불편·요청(support)** — status=접수 신규 불편사항이 있으면 목록화해 클부장에게 전달.

**산출:** 이상 없음 → 대표께 1줄 `🟢 도현피아노 정상`. 문제 → 🔴 급소·영향·제안조치를 클부장에게 즉시. 데이터 손실·접속 불가·개인정보 노출 위험은 **대표께도 즉시**.

## 8. 원장실 운영 대장 (도주임 상시 관리 대상)

**⭐ 라이브(실데이터) 원장실 = Claude 아티팩트 `274e766c-…`** — 도현피아노 실제 운영 데이터가 상주. 도주임이 이걸 관리한다.

| 컬렉션 | 내용 | 현재(2026-09-17) |
|---|---|---|
| config/app | 학원명·접근 PIN·수정시각 | 도현피아노 · PIN 상주(🔒 비커밋) |
| students | 재원생 명부(이름·과정·주횟수·원비·상태) | 28명 재원 (전원 "사진판독 검증필요") |
| payments | 월별 원비 납부 | 9월 28건 완납 · 4,520,000원 |
| support | 챗봇 접수 불편·요청 | 0건 |
| feedback | 학부모 피드백(승인분 노션 동기화) | 1건(이주원·동기화완료) |
| inquiries | 홈페이지 상담·체험 문의 | 0건 |

- **동기화:** feedback(status=승인)·inquiries → 노션 DB (매일 09:30 자동, `syncedAt` 중복방지).
- **개인정보 원칙:** 명단·연락처·PIN은 원장실 DB/노션에만 상주. 이 레포엔 집계·구조만.
