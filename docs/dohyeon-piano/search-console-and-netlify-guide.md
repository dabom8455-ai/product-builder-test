# 🌐 도현피아노 — netlify 중복 정리 & 서치콘솔 DNS 인증 가이드

> 대표님이 직접 하셔야 하는 2가지 관리 작업을, 화면 순서대로 쉽게 정리했습니다.
> 작성: 도주임 · 2026-09-17 · 대상: `dohyeonpiano.com`(Cloudflare) + Netlify 배포

---

## 왜 이걸 해야 하나 (30초 요약)

- **중복 정리:** 같은 홈페이지가 `dohyeonpiano.com`(정식)과 `dohyeonpiano.netlify.app`(무료 곁방) **두 주소에서 동시에** 보이는 상태. 검색엔진이 "뭐가 진짜지?" 헷갈려 순위가 쪼개짐 → **netlify.app을 .com으로 자동 전달(301)** 시켜 하나로 합친다.
- **서치콘솔 인증:** 구글·네이버에게 "이 사이트 주인 나예요"를 등록해야 검색 노출·유입 지표를 본다. 지금 쓰던 **파일 방식**은 Cloudflare가 주소를 바꿔버려 불안정 → **DNS(TXT) 방식**으로 바꾸면 깔끔하게 해결.

두 작업 모두 **대표님 로그인이 필요한 화면 작업**이라 도주임이 대신 클릭할 수 없어, 순서만 정확히 짚어드립니다.

---

## Part 1. netlify.app 중복 없애기 (Netlify 대시보드 · 약 1분)

가장 확실한 방법은 Netlify에서 **정식 도메인(.com)을 "기본 도메인"으로 지정**하는 것. 그러면 Netlify가 `netlify.app` 접속을 **자동으로 .com으로 넘겨줍니다(301).** 코드 수정 불필요.

1. **app.netlify.com** 접속 → 로그인.
2. 도현피아노 사이트(이름에 `dohyeonpiano` 포함) 클릭.
3. 상단 **Domain management**(도메인 관리) 메뉴 클릭.
4. **Production domains** 목록에서 `dohyeonpiano.com` 우측 **⋯(점 3개)** → **Set as primary domain**(기본 도메인으로 설정) 클릭.
5. 안내창에 뜨는 **"Redirect all …netlify.app to primary domain"**(넷리파이 주소를 기본 도메인으로 리다이렉트) 체크박스 **켬** → 저장.

✅ 끝나면: 브라우저에서 `dohyeonpiano.netlify.app` 을 열었을 때 **자동으로 `dohyeonpiano.com` 으로 튕겨야** 정상입니다. (도주임이 다음 점검 때 확인해 🟢로 바꿔드립니다.)

> 만약 위 메뉴가 안 보이거나 사이트가 여러 개라 헷갈리면, 사이트 이름만 알려주세요 — 어느 걸 눌러야 하는지 짚어드리겠습니다.

## Part 2. 구글 서치콘솔 — DNS(TXT) 방식 인증 (약 5분)

**준비물:** ① 구글 계정 ② Cloudflare 로그인(도현피아노 도메인 관리하는 곳).

### 2-1. 구글에서 인증값 받기
1. **search.google.com/search-console** 접속 → 로그인.
2. 왼쪽 위 속성 선택 → **속성 추가**.
3. 두 가지 유형 중 **"도메인"**(왼쪽, DNS 방식) 선택 → `dohyeonpiano.com` 입력 → 계속.
4. 화면에 **TXT 레코드 값**이 나옵니다. 예: `google-site-verification=xxxxxxxxxxxx…`
   → 이 값을 **복사**(전체).

### 2-2. Cloudflare에 TXT 붙여넣기
5. **dash.cloudflare.com** 접속 → 로그인 → `dohyeonpiano.com` 클릭.
6. 왼쪽 **DNS** → **Records**(레코드) → **Add record**(레코드 추가).
7. 아래처럼 입력:
   - **Type(유형):** `TXT`
   - **Name(이름):** `@`  ← (골뱅이. "도메인 루트"라는 뜻)
   - **Content(내용):** 아까 복사한 `google-site-verification=…` 값 그대로 붙여넣기
   - **TTL:** Auto(자동)
   - **Proxy status:** TXT는 프록시 대상이 아니라 회색 구름/해당 없음으로 그냥 둠
8. **Save**(저장).

### 2-3. 구글로 돌아가 확인
9. 5~10분 기다린 뒤(반영 시간), 구글 서치콘솔 화면의 **"확인"** 버튼 클릭.
   → "소유권이 확인되었습니다" 나오면 완료! 🎉 (안 되면 10분 더 기다렸다 재시도)

> **왜 이 방식이 좋나:** TXT는 "도메인 등기소에 찍는 도장"이라, Cloudflare가 페이지 주소를 바꾸든 말든(308 문제) 아무 상관 없이 인증됩니다. 한 번 해두면 계속 유지돼요.

## Part 3. 네이버 서치어드바이저 (선택 · 같은 원리)

1. **searchadvisor.naver.com** → 로그인 → **웹마스터 도구** → 사이트 등록에 `https://dohyeonpiano.com` 입력.
2. 소유확인 방법에서 가능하면 **HTML 태그** 대신 문제가 적은 방식을 고르고, 네이버가 주는 값을 위와 같은 요령으로 처리.
   - 네이버는 DNS(TXT)를 항상 지원하진 않아, HTML 파일/태그만 될 수 있습니다. 그 경우 **Part 1(기본 도메인 정리)** 을 먼저 끝내면 파일 방식도 안정적으로 동작합니다.
3. 등록 후 **사이트맵 제출**: `https://dohyeonpiano.com/sitemap.xml` 등록해두면 색인이 빨라집니다.
