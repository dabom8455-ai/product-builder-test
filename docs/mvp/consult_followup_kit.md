# 상담 후속 관리 키트 (컨시어지 MVP v1)

> 목적: **상담 온 분을 놓치지 않고 등록까지 잇는다.** 흘리던 리드를 잡는다.
> 근거: 1차 문제 파악 인터뷰 — 1등 문제 "상담→등록 전환", 기존 대안 전무.
> 방식: 《린 스타트업》 컨시어지 MVP — **먼저 사람이 수동으로** 돌려 효과를 증명 → 검증되면 자동화(L2).
> 관리: ①학원운영팀 + 클부장 · 데이터: 노션 ① 리드 DB

---

## 0. 딱 하나의 원칙
> **상담 당일 기록 + 2일 안에 첫 후속.** 바빠도 이 둘만 지키면 전환율이 오른다.
> (인터뷰에서 확인된 누수 원인 = "바빠서 후속을 못 함" → 시점을 미리 정해두면 해결)

---

## 1. 후속 타임라인 (상담 후 무엇을, 언제)

| 시점 | 할 일 | 리드 DB 상태 |
|------|-------|--------------|
| **당일 (D0)** | 상담 끝나면 **즉시 리드 DB에 기록** + 저녁에 **감사 문자**(템플릿 A) | `상담완료` |
| **D+2** | **1차 후속** — 안내 + **소개 인포그래픽 첨부**(템플릿 B) | (유지) |
| **D+5** | **2차 후속** — 부드러운 리마인드 (템플릿 C) | (유지) |
| **D+10** | 마지막 인사 — 문은 열어둔다 (템플릿 C 변형) | 무응답 시 `보류` |
| 등록/포기 확정 시 | 최종 상태 갱신 | `등록` 또는 `이탈` |

> 핵심은 **D+2 첫 후속**이다. 대부분은 여기서 갈린다.

---

## 2. 문자 템플릿 (복사해서 [대괄호]만 채우기)

### 템플릿 A — 상담 당일 감사 (D0 저녁)
```
안녕하세요 [학부모님 성함]님, 도현피아노 원장입니다.
오늘 [아이 이름] 상담으로 찾아와 주셔서 감사했습니다 :)
오늘 나눈 [과정/시간표] 내용 참고하시고,
궁금한 점 있으시면 편하게 연락 주세요. 좋은 저녁 되세요!
```

### 템플릿 B — 1차 후속 + 인포그래픽 첨부 (D+2)
```
[학부모님 성함]님, 도현피아노입니다 :)
지난 상담 이후 [아이 이름]에게 도움이 될 만한
저희 학원 소개 자료를 함께 보내드려요. (이미지 첨부)

- [아이 이름]에게 맞는 과정: [추천 과정]
- 시작 가능 시간: [요일/시간]

천천히 보시고 결정 도와드릴 부분 있으면 말씀 주세요!
```
> 👉 이 문자에 **'도현피아노 소개 인포그래픽'**(별도 제작)을 함께 첨부한다.

### 템플릿 C — 2차 리마인드 (D+5)
```
[학부모님 성함]님, 안녕하세요 도현피아노입니다.
[아이 이름] 레슨 시작은 편하게 결정하셔도 괜찮아요 :)
[이번 달 시작 시 첫 달 교재 제공 / 지금 반에 자리 여유]가 있어
혹시 도움이 될까 하여 알려드립니다.
부담 갖지 마시고 궁금하신 점 언제든 편히 연락 주세요!
```

> 톤 원칙: **부담 없이, 아이 이름을 꼭 넣고, 팔지 말고 도와준다는 태도.** 스팸처럼 느껴지면 역효과.

---

## 3. 리드 기록 루틴 (상담 즉시 30초)
상담이 끝나면 바로 노션 ① 리드 DB에 한 줄 추가:
- **리드명**(아이/학부모 구분되게) · **유입경로** · **연락처** · **아이나이** · **문의내용** · **유입일** · **상태** · **담당**
- 후속을 보낼 때마다 비고에 날짜 메모 (예: "D+2 문자 발송")

---

## 4. 측정 (이게 MVP의 성패)
매주 리드 DB에서 확인:
- **상담 건수** (그 주 `상담완료` 수)
- **등록 전환율** = 등록 ÷ 상담 (%)
- 후속을 지킨 주 vs 못 지킨 주의 전환율 비교

> 목표: **4주 운영 후 "후속 관리로 전환율이 오르는가?"에 예/아니오로 답한다.** (= 90일 1차 주기의 검증 질문)

---

## 5. 다음 단계 (검증 후 자동화)
- 후속 효과가 확인되면 → D0/D+2/D+5 문자 **자동 발송**으로 전환(L2).
- 그때 이 키트가 그대로 **판매 상품(학원용 상담 후속 자동화)**의 설계도가 된다.
