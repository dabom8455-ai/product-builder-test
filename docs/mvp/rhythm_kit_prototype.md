# 리듬·박자 디지털 프로토타입 — 실행계획 (컨시어지 MVP)

> 출처: 2026-09-10 어전회의 집행안(`docs/court/2026-09-10_어전회의_리듬키트_장계.md`).
> 성격: **실물 키트 제작 전, 무료·디지털로 수요를 먼저 재는** 린 스타트업 검증. (오즈의 마법사식)

## 1. 제작물 (✅ 완료)
- **온라인 리듬·박자 연습기(웹)** — 작동하는 메트로놈 + 초등 리듬 카드 따라치기.
  🔗 https://dohyeon-piano.netlify.app/rhythm/
  - 소스: `tools/rhythm-trainer.html` (홈페이지 저장소 `dohyeon-piano/public/rhythm/index.html`로 배포) · claude.ai 미러: artifact/4070783b
  - 기능: BPM 40~200·박자표(2/4·3/4·4/4)·시각 펄스·탭템포 메트로놈 / 3단계 리듬 카드(따·따다·쉼표), 소리에 맞춰 음표가 빨갛게 켜지며 손뼉 따라치기 / 하단 학부모 상담 CTA(전화·주소).
  - 재고·제작비 0. 링크만 공유하면 폰에서 바로 사용.

## 2. 검증 설계 (측정 → 견인)
| 전선 | 무엇 | 성공 잠정 기준 |
|---|---|---|
| **원내 시범** (교무) | 다음 주 초 3~5명에게 수업 중 사용, 반복 사용·집중도 관찰 | 시범 학생 과반이 "또 하고 싶다" + 2회차 이상 사용 |
| **카페 수요** (마케팅) | 마더 모현에 링크+안내 게시, 신청/반응 수집 | 신청·문의 **10건 이상** (댓글·문자 합산) |

> ⚠️ 경계(어전회의): 무료 디지털 관심 ≠ 실물 구매 의사. 10건을 넘겨도 **"돈 낼 의향"**을 상담에서 따로 확인하기 전엔 실물 대량 제작 금지.

## 3. 담당·일정
- **운영팀장(클부장 집행):** ✅ 웹 프로토타입 제작 완료. (추후 인쇄용 리듬카드 PDF는 수요 확인 후)
- **교무팀장(원장):** 다음 주 초, 수업 중 3~5명 시범 배포 → 반응 메모.
- **마케팅팀장:** 카페 게시(아래 §4 문안) → 신청·문의 수를 노션 「콘텐츠 발행·성과 로그」 또는 별도 메모로 집계.
