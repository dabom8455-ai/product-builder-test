# 월말 학부모 진도 리포트 자동화 — ① 학원운영팀 **최우선 자동화 #1**

> 지시: 대표(원장) · 2026-09-09 · 총괄: 클부장 · 실행: ① 학원운영팀
> **왜 #1:** 학부모 신뢰·재등록·차별화의 핵심. "운영은 AI가, 교육은 선생님이" 비전의 **얼굴**이자, 그대로 파는 B2B 상품('학부모 리포트 자동화').
> 상담 후속(리드)은 **상시 기록 업무로 하향** — 고객 오면 데이터만 쌓는다(급하지 않음).

---

## 1. 무엇을 (What)
**매달 말 1회**, 학부모에게 **카카오톡**으로 **아이별 진도 리포트**를 보낸다. 구성 6요소:
1. **발전 상태** — 이번 달 얼마나 자랐나
2. **현재 진도** — 배운 곡/교재 구간
3. **좋은 점** — 강점 1~2
4. **개선할 점** — 다음 달 함께 볼 것 1
5. **원장 선생님 피드백** — 따뜻한 한마디
6. **연주 영상** — 아이가 피아노 치는 모습 (원장 촬영)

## 2. 자동화 단계 (L0 → L1 → L2)
| 단계 | 상태 | 내용 |
|---|---|---|
| L0 | 현재 | 원장이 매달 손으로 다 작성·발송 (시간 많이 듦) |
| **L1** | **이번 달 목표** | 원장이 학생당 **4줄만 입력** → **AI가 리포트 문장 자동 생성** → 원장 검토 → 카톡 발송(영상 첨부). 발송 로그 자동 기록 |
| L2 | 이후 | 진도 데이터 누적 → 강점·진도 초안 자동 + (카카오 알림톡 API 연동 시) **발송까지 자동** → **판매 상품화** |

> ⚠️ 완전 자동 '발송'은 카카오톡 채널·알림톡(비즈니스 API)이 있어야 함 → L2에서. **지금 물길은 '생성 자동화'(L1)** — 원장의 가장 큰 시간을 없앤다.

## 3. 원장 월말 입력 양식 (학생당 30초)
> 이것만 채우면 나머지 문장은 AI가 만든다.
```
이름:
이번 달 진도(배운 곡/교재):
좋은 점(1~2):
개선점(1):
원장 한마디:
영상: O / X
```
- 클부장에게 그대로 붙여넣거나, 노션 「월간 진도 리포트」 DB에 입력.

## 5. 데이터 (기록)
- 노션 **「월간 진도 리포트(Progress Reports)」 DB** — 원생·월·진도·강점·개선점·원장피드백·영상여부·발송여부·발송일.
- 원생은 「원생 명단」 DB와 연결 → 매달 누적되면 L2 자동 초안의 재료.

## 6-1. 🔁 매달 이어지는 연속 사이클 (핵심 설계)
> **한 달로 끝나지 않는다.** 이번 달 발송 → 다음 달은 지난달을 이어받아 **성장 이야기**로 쌓인다.

```
[매월 25일] 원장이 학생당 4줄 입력(진도·강점·개선점·영상)
        │
        ▼
[즉시] 학원운영팀 AI가 원장피드백 작성
        ├─ 근거①: 이번 달 원장 입력
        └─ 근거②: 같은 원생의 '지난달 원장피드백'을 조회해 참조   ← 연속성
        → 지침(parent_feedback_guide.md)대로 작성 → 발송여부=생성완료
        │
        ▼
[검토·발송] 원장이 확인 → 카톡 발송(영상 첨부) → 발송여부=발송완료
        │
        ▼
[다음 달 25일] 전월 명단을 복제해 새 '월' 행 자동 생성(28행) → 위 흐름 반복
```

- **역할 분담:** 원장=사실 입력 / **학원운영팀 AI=원장피드백 작성**(지침 준수) / 원장=검토·발송. → [`parent_feedback_guide.md`](parent_feedback_guide.md)
- **연속성의 재료:** 「월간 진도 리포트」 DB는 `원생`(→명단)·`월`로 같은 아이의 과거 리포트를 언제든 조회 가능. AI는 **직전월 `원장피드백`을 읽고** 이번 달을 쓴다(반복 금지·성장 서사·지난달 약속 회수).
- **다음 달 행 생성:** 매월 25일 루틴이 **전월 28행을 복제(월만 변경, 원생 연결 유지)** → 원장은 새 달 칸만 채우면 된다. (첫 실행 2026-09은 클부장이 수동 생성 완료)
- **누적 가치:** 달이 쌓일수록 L2(강점·진도 초안 자동)와 **B2B 판매 상품('학부모 리포트 자동화')**의 데이터가 된다.
