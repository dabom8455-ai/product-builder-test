# 월말 학부모 진도 리포트 자동화 — ① 학원운영팀 **최우선 자동화 #1**

> 지시: 대표(원장) · 2026-09-09 · 총괄: 클부장 · 실행: ① 학원운영팀
> **왜 #1:** 학부모 신뢰·재등록·차별화의 핵심. "운영은 AI가, 교육은 선생님이" 비전의 **얼굴**이자, 그대로 파는 B2B 상품('학부모 리포트 자동화').
> 상담 후속(리드)은 **상시 기록 업무로 하향** — 고객 오면 데이터만 쌓는다(급하지 않음).

---

## 1. 무엇을 (What)
**매달 말 1회**, 학부모에게 **카카오톡**으로 **아이별 진도 리포트**를 보낸다. 구성 6요소:
1. **발전 상태** — 이번 달 얼마나 자랐나
2. **현재 진도** — 배운 곡/교재 구간
3. **좋은 점** — 강점 1~2
4. **개선할 점** — 다음 달 함께 볼 것 1
5. **원장 선생님 피드백** — 따뜻한 한마디
6. **연주 영상** — 아이가 피아노 치는 모습 (원장 촬영)

## 2. 자동화 단계 (L0 → L1 → L2)
| 단계 | 상태 | 내용 |
|---|---|---|
| L0 | 현재 | 원장이 매달 손으로 다 작성·발송 (시간 많이 듦) |
| **L1** | **이번 달 목표** | 원장이 학생당 **4줄만 입력** → **AI가 리포트 문장 자동 생성** → 원장 검토 → 카톡 발송(영상 첨부). 발송 로그 자동 기록 |
| L2 | 이후 | 진도 데이터 누적 → 강점·진도 초안 자동 + (카카오 알림톡 API 연동 시) **발송까지 자동** → **판매 상품화** |

> ⚠️ 완전 자동 '발송'은 카카오톡 채널·알림톡(비즈니스 API)이 있어야 함 → L2에서. **지금 물길은 '생성 자동화'(L1)** — 원장의 가장 큰 시간을 없앤다.

## 3. 원장 월말 입력 양식 (학생당 30초)
> 이것만 채우면 나머지 문장은 AI가 만든다.
```
이름:
이번 달 진도(배운 곡/교재):
좋은 점(1~2):
개선점(1):
원장 한마디:
영상: O / X
```
- 클부장에게 그대로 붙여넣거나, 노션 「월간 진도 리포트」 DB에 입력.

## 4. 표준 리포트 템플릿 (카카오톡 발송용)
```
[도현피아노 · OO이 O월 진도 리포트 🎹]

안녕하세요 어머님, 도현피아노 이보나 원장입니다.
OO이의 이번 달 피아노 이야기를 전해드려요.

📖 이번 달 진도
· (배운 곡/교재 구간)

🌱 이만큼 자랐어요
· (좋은 점 1~2)

🎯 다음 달 함께 볼 부분
· (개선점 1)

💬 원장 선생님 한마디
(따뜻한 피드백·격려)

🎥 OO이의 연주 영상도 함께 보내드려요! (아래 영상)

다음 달도 즐겁게 함께해요 :) 궁금한 점은 언제든 편하게 연락 주세요.
```

## 5. 데이터 (기록)
- 노션 **「월간 진도 리포트(Progress Reports)」 DB** — 원생·월·진도·강점·개선점·원장피드백·영상여부·발송여부·발송일.
- 원생은 「원생 명단」 DB와 연결 → 매달 누적되면 L2 자동 초안의 재료.

## 6. 운영 흐름 (매달 25일~말일)
1. **25일:** 클부장이 원장에게 "이번 달 리포트 입력" 리마인드(자동 루틴).
2. 원장: 학생별 4줄 입력(또는 클부장에게 구술) + 아이별 영상 촬영.
3. 클부장/AI: 학생별 카톡 리포트 문장 **자동 생성** → 원장 검토.
4. 원장: 카카오톡으로 학부모에게 발송(영상 첨부).
5. 발송 로그 DB 기록 → 발송률 집계.

## 7. 성공 지표
- **발송률 100%**(전원 매달), 학부모 반응(답장·만족), **재등록률 상승**.

## 8. 판매 모듈 연결 (B2B)
검증되면 → "학부모 진도 리포트 자동화"를 다른 학원에 판매(구독/설치형). ②마케팅·③수익화로 이관.
