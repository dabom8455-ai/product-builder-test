# 리드 상태 전이 규칙 (Lead Status SOP)

> ①학원운영팀 실행 + ⑤인프라 표준. 노션 [① 리드 DB](https://app.notion.com/p/fd3766edbddc47edb931ba8f69f34c06)의 **상태** 값을 모두가 같은 기준으로 갱신한다.
> **왜:** 상태가 제멋대로면 전환율을 믿을 수 없다. 이 규칙이 90일 1차 주기 측정의 바닥이자, 나중에 팔 "상담 자동화 모듈"의 뼈대다.
> 작성: 클부장 · 2026-09-09

---

## 1. 상태 6단계 (한 방향 흐름 + 이탈/보류)
```
신규 → 상담예약 → 상담완료 → 등록
                     └→ 보류(나중) / 이탈(끝)
```

| 상태 | 의미 | 이 상태로 바꾸는 시점(진입 조건) | 다음 행동 |
|------|------|-------------------------------|-----------|
| **신규** | 문의만 접수, 상담 전 | 전화·DM·폼·워크인으로 접촉 | 상담 일정 제안(24h 내) |
| **상담예약** | 상담 날짜 확정 | 날짜/시간 합의됨 | 전날 리마인드 |
| **상담완료** | 상담 진행, 등록 미확정 | 상담을 실제로 함 | **후속 카드 D+1~2 시작** |
| **등록** | 등록·결제 확정 | 시작일/반 확정 | 온보딩, 리드 종료(성공) |
| **보류** | 관심 있으나 지금 불가(자리·일정·비용) | 대표 판단 | **D+30 재접촉 목록**에 넣기 |
| **이탈** | 거절 명확 또는 무응답 3회 | 아래 이탈 규칙 | 사유 1줄 기록 후 종료 |

## 2. 절대 규칙 (전환이 새지 않게)
1. **'상담완료'에서 움직임 없이 하루를 넘기지 않는다** — 반드시 후속(문안 카드)이 돈다. "재연락 대기"는 방치가 아니라 **우리가 먼저 연락하는 날짜를 잡는 것**.
2. **보류·이탈은 사유 1줄 필수** (비고 칸). 사유 없는 이탈 금지 — 왜 놓쳤는지가 다음 개선의 재료.
3. **이탈 판정은 "무응답 3회 후" 또는 "명확한 거절"** 일 때만. 성급한 이탈 처리 금지.
4. 상태를 바꾸면 **② 상담 DB의 결과**(등록/보류/이탈/재상담)와 어긋나지 않게 맞춘다.

## 3. 전환율 측정 (90일 1차 주기)
- **상담→등록 전환율 = 등록 수 ÷ 상담완료(누적, 등록 포함) 수**
- 매주 월요일 루틴이 이 숫자를 집계·기록한다. (숫자가 낮으면 후속 문안/타이밍부터 개선)
- 부가 지표: 평균 후속 횟수, 보류→등록 회수율.

## 4. 자동화 경로 (판매 모듈 후보)
- **L0(현재)** 수동: 원장이 상태 갱신 + 문안 복붙.
- **L1** 반자동: 상태 바뀌면 후속 문안·리마인더 자동 제안(로비서/클부장).
- **L2** 완전자동: 리드 접수→상태 전이→후속 발송→측정까지 자동. → **이게 다른 학원에 파는 상품.**

> 요약: 상태는 위 표대로만 바꾼다. 애매하면 클부장에게 한 줄 — "OO 리드 지금 상담완료 맞아?" → 정리해 드립니다.
