# 재무 1장 (Financial Snapshot) — 도현피아노

> ③ 수익화팀 · 클부장 · 2026-09-08 기준 · 대표 입력값으로 산출한 **살아있는 재무 현황**.
> 값이 바뀌면 여기부터 고친다. (수강료 등 확정치는 `docs/infra/business_profile.md`와 일치)

## "재무 1장"이 뭔가요? (쉽게)
> **"우리 학원이 한 달에 얼마 벌고, 얼마 쓰고, 얼마 남는지"**를 한 표로 보는 겁니다.
> 여기에 **"몇 명부터 흑자인가(손익분기)"**와 **"학생 한 명 더 받으면 얼마 남나"**까지 자동으로 나옵니다.
> 이 숫자가 있어야 → 수강료를 올릴지, 학생을 몇 명 더 받아야 할지, 자동화에 얼마 투자할지 **근거 있게** 정합니다.

## 입력값 (대표님 제공)
| 항목 | 값 |
|------|-----|
| 원생 수 | 24명 |
| 원생 1인당 평균 월 수강료 | 150,000원 |
| 월 임대료 (부가세 포함) | 1,980,000원 (180만 + 부가세 18만) |
| 월 관리비·공과금 | 200,000원 |
| 월 기타 고정비 (피아노 리스·보험 등) | 50,000원 |
| 월 변동비 (교재·행사) | 50,000원 |

## 산출 결과 (자동 계산)
| 지표 | 계산 | 값 |
|------|------|-----|
| **월 매출** | 24명 × 15만 | **360만 원** |
| **월 총비용** | 198만 + 20만 + 5만 + 5만 | **228만 원** |
| **월 순이익** *(원장 인건비 전)* | 360만 − 228만 | **🟢 132만 원** |
| **원생 1인당 기여이익** | 15만 − (변동비 5만÷24) | 약 **14.8만 원** |
| **손익분기 원생 수** | 고정비 223만 ÷ 14.8만 | 약 **15명** |

---

## 📊 이 숫자가 말해주는 것 (클부장 해석)

1. **지금 흑자입니다.** 손익분기가 **약 15명**인데 현재 **24명** → 9명분(월 약 133만)의 여유. 안정권입니다.

2. **다만 "순이익 132만"은 곧 원장님 인건비이기도 합니다.** 원장님이 직접 다 가르치시니, 이 132만이 사실상 **원장님 한 달 몫**에 가깝습니다. 풀타임 노동 대비로 보면 **아직 낮습니다.** → **키울 여지가 크다**는 뜻.

3. **학생 1명 = 월 +14.8만, 거의 그대로 이익.** 고정비(임대료 등)는 이미 다 내고 있으니, **추가 원생은 대부분 순이익**입니다. 예:
   - +6명(30명) → 순이익 약 **221만**
   - +11명(35명) → 순이익 약 **295만**
   - 즉 **원생을 늘리는 게 수익에 가장 직접적.** (그래서 마케팅·상담전환이 곧 돈)

4. **또는 단가.** 수강료를 1만원 올리면(24명) 월 +24만. 심화·입시 과정 비중을 높이는 것도 방법.

## 클부장 제안 (수팀장)
- **1순위 지렛대 = 원생 수 증대.** → ②마케팅(유튜브)·①상담전환(90일 주기)이 곧 재무 개선. 세 팀이 한 방향.
- **목표 설정 제안:** "월 순이익 250만" = 원생 약 33명. → 마케팅·전환의 **구체적 목표(리드 수)**로 환산 가능.
- 다음 단계: 이 스냅샷을 **⑥ 수강료·⑦ 매출 DB**로 옮겨 매달 자동 갱신.

> ⚠️ 주의: 세금(종합소득세)·4대보험 등은 아직 미반영. 원장 실수령은 이보다 낮을 수 있음(추후 반영).
