## 📊 이 숫자가 말해주는 것 (클부장 해석)

1. **튼튼한 흑자입니다.** 손익분기 **약 15명**인데 현재 **28명** → 약 1.9배. 원생이 절반으로 줄어도 적자는 아닙니다. 안정권.

2. **월 영업이익 209만 = 사실상 원장님 한 달 몫.** 원장님이 직접 다 가르치시니 이 209만이 원장님 인건비에 가깝습니다. 풀타임 대비 **아직 키울 여지가 큽니다.**

3. **학생 1명 = 월 +16.1만, 거의 그대로 이익.** 고정비는 이미 다 내고 있어 **추가 원생은 대부분 순이익**:
   - +5명(33명) → 영업이익 약 **290만**
   - +10명(38명) → 약 **370만**
   - → **원생 증대가 수익에 가장 직접적.** (마케팅·상담전환 = 곧 돈)
   - ※ 원생이 크게 늘면 책값(교재비)도 비례해 늘 수 있음 → 추후 반영.

4. **단가 레버도 있음.** 기초 20명(71%)을 중급으로 끌어올리면 객단가↑. 객단가 16.1→17.1만이면(28명) 매출 +28만 → 영업이익 237만.

5. **매출 구조:** 주5회 15명(54%)이 매출 핵심 → **리텐션이 수익 방어선**. 이탈 1명 = 월 −16만.

> **신규 1명의 금전가치 = 월 16.1만 = 연 193만.** 마케팅 1건 전환이 이만큼의 가치.
> → ②블로그·스레드(유입) + ①상담전환(90일 주기) + 리텐션(진도리포트)이 전부 이 숫자를 움직인다. 세 팀 한 방향.

### ✅ 1차 수익 목표 (2026-09-10 대표 확정 — 책값 반영 후 B안)
**재원 28 → 34명(+6), 월 영업이익 209만 → 약 306만(월 300만+ 달성).** 기한: 90일 1차 주기 내.
> 책값 20만 고정비 반영 후 월 300만을 정확히 맞추는 선택(B): +6명(34명). (34×16.1 − 243 ≈ 306만)
