## PART 2. 회계 관리 구조 (어떻게 관리할 것인가)

### 2-1. 2부문 분리 회계 (A 학원 / B 시스템 판매)
모든 수입·지출에 **부문 태그**를 붙인다. 계정과목 최소 세트:

| 구분 | A. 학원 운영 | B. 시스템 판매 |
|------|-------------|---------------|
| **수입** | 원비 | 트립와이어·셋업·구독·전자책 |
| **비용** | 임대·관리·공과·교재 | 결제수수료(크몽/Gumroad)·광고비·제작외주 |
| **지표** | 객단가·BEP·리텐션 | 건당마진·MRR·CAC/LTV |

### 2-2. 월 마감 루틴 (재팀장 주관)
> **매월 말일, 한 시간이면 끝나는 루틴.**
1. 대시보드 **매출/지출 ledger**에 그 달 수입·지출을 부문 태그로 입력 확인.
2. 부문별 **매출·비용·영업이익** 집계 → `financials_snapshot.md` 갱신.
3. 전월 대비 증감·이상치 점검(미납, 비용 급증).
4. 요약 1줄을 **의사결정 로그**에 기록, 클부장 검토 → 대표 보고.
- (장래) 노션 **「매출·비용」 DB** 신설 시 월 1행 자동 집계로 승격(데이터 레지스트리 ⑦ 대기 항목).

### 2-3. 세무·컴플라이언스 체크
- **사업자·부가세·현금영수증**: 매출 발생 시 의무. 학원(면세/과세 구분)과 시스템 판매(과세) 성격 다름 → 세무사 1회 자문 권고.
- **크몽·Gumroad 정산·수수료·해외매출**: 플랫폼 수수료를 비용으로, 해외매출은 환율·부가세 영세율 여부 확인.
- **교습비 등록가**: 운영가 일부가 교육청 등록가보다 높음(`tuition_pricing.md`) → 정정·재등록 권고(잔여 조치).

## PART 4. 회계 자동화 로드맵 (L0→L2) — 그리고 상품화
1. **L0(지금):** 대시보드 ledger + 월 마감 수기. 부문 태그만 지킨다.
2. **L1:** 노션 「매출·비용」 DB로 월 1행 자동 집계 → 재무 1장 자동 갱신.
3. **L2:** 원생명단·결제 데이터 연결 실시간 재무 대시보드.
   → 이 **'가격표 × 원가 × 손익분기' 계산 자체를 외부 학원용 상품**(재무 자가진단 템플릿)으로. = ③팀 수익화 씨앗.
