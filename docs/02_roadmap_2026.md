# 2026 로드맵 — MVP 출시까지

> **목표:** 우리 학원 자동화 시스템 MVP를 시장에 내놓고 첫 고객 피드백을 받는다.
> **원칙:** 완벽함보다 물길. 4개 팀 병렬 진행, 클부장이 우선순위 조정.

---

## 큰 그림 (4단계)

```
[1단계] 뼈대 수립        [2단계] 검증          [3단계] 패키징        [4단계] 출시·피드백
회사 구조·팀 정의   →   우리 학원에 자동화  →  외부가 쓸 수 있게   →  1호 고객 전달
(=지금 완료)            1개 실제 적용·검증      MVP로 포장            피드백으로 수정
```

---

## 단계별 상세

### 1단계 — 회사 뼈대 수립  ✅ (본 문서 세트로 완료)
- [x] 회사 헌장 (미션·비전·가치·목표)
- [x] 조직 구조 & 클부장 운영체계
- [x] 4개 팀 정의 + 세부업무 분할
- [ ] 대표 확정: North Star 목표 수치, 1차 착수 팀 우선순위

### 2단계 — 우리 학원에서 자동화 1개 검증  🎯 (다음 초점)
- [ ] ①학원운영팀: "운영 업무 지도" 작성 → 가장 아픈 잡무 1개 선정
- [ ] 그 1개를 L0→L1→L2로 자동화하여 **우리 학원에 실제 적용**
- [ ] ③수익화팀: 우리 학원 재무 현황 1장 정리 (가격 근거 확보)
- [ ] 4주간 실제 운영하며 효과(절감 시간) 측정

### 3단계 — MVP 패키징
- [ ] 검증된 자동화 1개를 **외부 학원이 쓸 수 있는 형태**로 정리 (설치/사용 가이드 포함)
- [ ] ③수익화팀: 가격·제공 형태 확정
- [ ] ②마케팅팀: 판매 페이지 + 사례(우리 학원 결과) 준비
- [ ] ④전자책팀: 관련 리드마그넷/전자책 1개 초안

### 4단계 — 출시 & 첫 피드백
- [ ] 1호 고객(외부 학원/원장)에게 전달
- [ ] 피드백 수집 → 우선순위화 → 수정
- [ ] 선순환 시작: 첫 수익 → 다음 자동화 모듈에 재투자

---

## 클부장의 조정 포인트

- **병목 감시:** 2단계에서 ①의 산출물이 늦으면 3·4단계 전체가 밀린다 → 최우선 관리.
- **동시 진행 가능한 것:** ②마케팅 채널 실험, ④전자책 목차 잡기는 2단계와 **병렬**로 시작 가능.
- **대표 결정 대기 항목:** 목표 수치 확정, 1차 착수 팀/자동화 대상 최종 선택.
