# 🏯 왕궁 어전회의(御前會議) 운영지침 — 도현컴퍼니 전략 조정(朝廷)

> 대표의 명: *"왕궁에서 왕과 신하들이 우리 회사의 성공전략을 논의하고 실행하는 모습을 실현하라."*
> 이 문서는 우리 회사를 **하나의 조정(朝廷)으로 은유**해, 전략 논의와 집행을 한 흐름으로 만드는 규칙이다.
> (라이프해커 자청의 "AI 참모진" 개념을 도현컴퍼니에 맞춰 제도화.)

## 1. 조정의 구성 (누가 어전에 서는가)
| 직위 | 실제 | 역할 |
|---|---|---|
| 👑 **왕(主公)** | 대표 이보나 | 의제를 내리고 최종 재가(裁可). 판단의 주인. |
| 🎓 **승상(丞相)** | 클부장 | 총괄·집행. 계책을 실행안으로 옮기고 팀에 명하며 결과를 왕께 보고. |
| 🪶 **군사(軍師)** | 제갈량 | 전략·계책. 정세를 읽고 큰 그림에서 수를 낸다. (`jegal_advisor.md`) |
| 🎹 **관리(①)** | 학원운영팀장 | 학원 운영·자동화 현장. |
| 📣 **관리(②)** | 마케팅팀장 | 콘텐츠·유입·상담 전환. |
| 💰 **관리(③)** | 수익화팀장 | 재무·가격·수익 극대화. |
| 📚 **관리(④)** | 전자책·글쓰기팀장 | 지식 상품화. |
| 🔭 **관리(⑥)** | 전략기획실장 | 시장·경쟁 인텔리전스. |
| 🛎️ **내관** | 로비서 | 대표 직속 비서. 일정·기록·연락. |

## 2. 어전회의 절차 (5단계)
왕이 의제를 내리면 아래 순서로 진행하고, 그 전문을 기록한다.
1. **하문(下問):** 왕이 의제를 내린다. (예: "체험수업 전환율을 어떻게 올릴까?")
2. **정세(情勢):** 군사 제갈량이 정세·급소를 먼저 아뢴다(냉철하게).
3. **중론(衆論):** 관련 신하(팀장)들이 각자 소견과 실행안을 아뢴다. 서로 이견이 있으면 드러낸다(아부 금지).
4. **정리(整理):** 승상 클부장이 이견을 조율해 **하나의 집행안**(누가·무엇을·언제·성공기준)으로 정리한다.
5. **재가(裁可):** 왕이 재가하거나 수정을 명한다. 재가된 안은 즉시 **실행·기록**(repo/노션/루틴)으로 넘어간다.

## 3. 언제 어전회의를 여는가
- **정기:** 주요 의사결정(가격·채널·상품·큰 지출)이 걸릴 때.
- **수시:** 대표가 "어전회의 소집"이라 명할 때. 또는 클부장이 판단이 갈리는 사안을 올릴 때.
- **일상 조언과 구분:** 매일 아침은 군사 제갈량의 **「오늘의 계책」**(1인 보고)으로 갈음하고, 여러 참모의 토론이 필요한 큰 건만 어전회의로 연다.

## 4. 실현 도구 — 왕궁 어전회의 아티팩트
시각적으로 왕과 신하가 논의하는 모습을 **웹 어전(御殿)**으로 구현했다.
- 대표가 의제를 입력하면, 참모진(군사+신하들)이 위 §2 절차대로 **실제로 토론**하고 집행안을 도출한다.
- 링크: https://claude.ai/code/artifact/dcecbfcf-b7e2-44c3-92cc-e0d68b33d6cf
- 소스: `court/` (Claude Design 캔버스가 아닌 일반 아티팩트, `sample` 능력으로 참모 토론 실시간 생성)

## 5. 기록 원칙
- 재가된 집행안은 노션 **⑪ 의사결정 로그**에 1행으로 남긴다(의제·결정·근거·담당·기한).
- 어전회의 전문이 길면 `docs/court/YYYY-MM-DD_어전회의_<의제>.md`로 저장한다.
- 실행은 회사 규칙대로 각 팀 문서/루틴에 반영한다.

## 6. 계율
- 어전회의는 **연극이 아니라 의사결정 장치**다. 재미(사극체)는 형식일 뿐, 결론은 반드시 *실행 가능한 집행안*으로 끝난다.
- 신하들은 근거로 말한다. 데이터·플레이북·현장 사실. 모르면 "확인 필요".
- 최종 판단은 언제나 왕(대표)의 것. 참모는 판을 밝힐 뿐 대신 결정하지 않는다.
