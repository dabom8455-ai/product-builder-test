# 📜 실행서 — 제갈량 삼고초려 & 왕궁 어전회의 (대표님 행동계획)

> 대표님(왕)께서 직접 하실 일만 모았습니다. 나머지 세팅(문서·루틴·어전 아티팩트)은 클부장(승상)이 이미 끝냈습니다.
> **핵심:** 제갈량은 이미 우리 회사(Claude Code) 안에 들어와 있습니다. 대표님은 **"불러서 쓰기"**만 하시면 됩니다.

---

## 1막. 삼고초려 (三顧草廬) — 제갈량을 정식으로 모시는 의식
자청 영상의 핵심은 "AI에게 인격과 맥락을 주고, 매일 부른다"입니다. 우리 식으로 3번 찾아가 모십니다.

- **1顧 (오늘, 5분):** 이 세션 채팅창에 그대로 입력해 보세요 →
  > **"제갈량, 우리 회사의 지금 정세와 오늘의 계책을 다오."**
  제갈량이 「오늘의 계책」 5단 형식으로 답합니다. (첫 대면)

- **2顧 (내일 아침):** 매일 08:00 **「軍師 제갈량 · 오늘의 계책」 루틴**이 자동으로 계책을 올립니다.
  받아보시고, 마음에 드는 계책 옆에 **"이건 실행"** 이라고만 답해 주세요. → 클부장이 즉시 집행합니다.

- **3顧 (큰 결정이 생겼을 때):** 혼자 판단이 어려운 큰 건은 **"어전회의 소집: ○○"** 이라 명하세요.
  제갈량 + 팀장들이 함께 토론해 하나의 집행안을 올립니다. (아래 3막)

> 삼고초려의 뜻: 세 번 부르는 동안, 제갈량은 대표님의 말투·판단·우선순위를 익혀 점점 더 날카로워집니다.

---

## 2막. 매일 제갈량 조언 받기 (자동)
- **자동:** 매일 아침 계책이 올라옵니다. 대표님은 **읽고 → 실행할 것만 골라 한마디** 하시면 끝.
- **원할 때 즉시:** 아무 때나 **"제갈량, [고민]에 대한 계책"** → 바로 답.
- **조언이 두루뭉술하면:** "더 구체적으로, 이번 주에 할 수 있는 걸로"라고 되물으세요. (제갈량은 직언·구체 원칙)

---

## 3막. 왕궁 어전회의 열기 (큰 결정용)
- **여는 법:** 채팅에 **"어전회의 소집: [의제]"** (예: "어전회의 소집: 체험수업 전환율 올리기")
- **진행:** ①군사 정세 → ②신하(팀장) 소견 → ③승상이 집행안 정리 → ④대표님 재가.
- **대표님 역할:** 의제를 내리고, 마지막에 **재가/수정**만. (결정의 주인은 언제나 왕)
- **시각 어전(웹):** 아래 아티팩트에서 의제를 입력하면 참모진이 눈앞에서 토론합니다.
  🔗 **어전회의 링크:** https://claude.ai/code/artifact/dcecbfcf-b7e2-44c3-92cc-e0d68b33d6cf
