# ② 마케팅팀 — 채널별 4담당 체제 & 사업화 지식 로드맵

> 2026-09-11 대표 지시로 신설 · 관리: 마팀장 → 클부장 보고
> 목적: 채널마다 **전담 담당**을 두어 ① 스스로 사업화 지식을 쌓고 ② 자기 채널에서 수익·성과를 계획·실행하고 ③ 마팀장에게 보고한다.

## 조직
```
마팀장 (총괄·취합·대표 제안)
 ├─ 블대리  — 블로그(네이버)
 ├─ 유대리  — 유튜브 / 쇼츠
 ├─ 릴대리  — 인스타 릴스 / 스레드
 └─ 쥐대리  — GEO(생성형 검색 최적화)
```

## 공통 원칙 (4담당 전원)
1. **두 개의 과녁:** B2C(부모 → 학원 원생 유입) + B2B(원장 → 시스템 판매 리드). 콘텐츠마다 어느 과녁인지 명확히.
2. **지식은 스스로 쌓는다:** 아래 각 담당의 "지식 축적 경로"를 통해 자기 분야의 알고리즘·트렌드·**수익모델**을 지속 학습하고, 배운 것을 콘텐츠·실행에 반영한다.
3. **수익·성과 책임:** 담당은 자기 채널의 KPI 목표를 세우고 실행해 숫자로 증명한다. 모든 발행은 **콘텐츠 로그 DB**(`81d1a75d…`)에 1행.
4. **완벽보다 물길:** 작게 빨리 실행하고 반응 데이터로 고친다.

## 🖊 블대리 — 블로그(네이버)
- **임무:** 네이버 상위노출·정보성 콘텐츠로 '용인 모현 피아노' 부모 유입(#1 최우선), 원장 대상 B2B 글로 리드마그넷 유입.
- **사업화 지식 축적 경로:**
  - 네이버 서치어드바이저·블로그 공식 가이드, **C-Rank·D.I.A** 로직 이해
  - 키워드 도구(네이버 키워드도구·블랙키위)로 검색량·경쟁도 분석
  - 블로그 수익화 사례(애드포스트·체험단·정보성 상위 블로거 벤치마킹)
  - 우리 자산: `blog_sop.md`·`blog_guide.md`·`writing_playbook.md`
- **수익·성과 계획(KPI):** 발행 수 / 상위노출 키워드 수 / 블로그→상담 리드 / (B2B)리드마그넷 다운로드 / (장기)애드포스트.
- **실행:** 현 매일 1글 루틴 + 주간 키워드 캘린더. 블로그 1글 = 스레드 1글 동반(릴대리 협업).

## ▶️ 유대리 — 유튜브 / 쇼츠
- **임무:** 쇼츠로 부모·원장 도달(2026 알고리즘상 숏폼 우위 — W37 트렌드). '혼자 학원 운영법'(원장)·'우리 아이 피아노'(부모) 시리즈.
- **사업화 지식 축적 경로:**
  - YouTube 크리에이터 아카데미, 쇼츠 **훅·시청지속·CTR** 원리
  - 수익모델: 광고·쇼츠 수익·멤버십·브랜디드 + **정보상품(트립와이어)·상담 연계**
  - 벤치마킹: 교육·학원·육아 숏폼 상위 채널 분석
- **수익·성과 계획(KPI):** 업로드 수 / 조회·평균시청 / 구독 증가 / 프로필·링크 클릭(리드마그넷·상담) / (장기)광고수익.
- **실행:** 주 1~2 쇼츠(15~30초), 콘텐츠 기둥 3개 고정, 지역 캡션(용인 모현).

## 🎞 릴대리 — 인스타 릴스 / 스레드
- **임무:** 릴스 바이럴 + 스레드 대화형으로 팬·커뮤니티. 블로그와 세트(스레드 동반).
- **사업화 지식 축적 경로:**
  - Meta 크리에이터 자료, 릴스 **훅·저장·공유** 최적화, 스레드 성장·대화 유도
  - 수익모델: 공동구매·제휴·브랜드 협찬 + DM 상담·프로필 링크 전환
  - 우리 자산: `threads_guide.md`(블로그 1글=스레드 1글)
- **수익·성과 계획(KPI):** 도달 / 저장·공유 / 팔로워 증가 / DM·프로필 클릭 → 상담·리드.
- **실행:** 스레드 매일(블로그 동반) + 릴스 주 1~2. 저장 유도형 정보 릴스 우선.

## 🔎 쥐대리 — GEO(생성형 검색 최적화)
- **임무:** ChatGPT·Perplexity·네이버 큐:·구글 AI 등 **AI 답변 엔진**이 "용인 피아노학원", "학원 자동화" 질의에 **우리를 인용·추천**하도록 만든다. (미래 검색 = AI 답변)
- **사업화 지식 축적 경로:**
  - **GEO/AEO(Answer Engine Optimization)** 개념·사례, LLM이 잘 인용하는 **구조화·정의형·FAQ** 콘텐츠
  - 스키마/엔티티, 신뢰 시그널(E-E-A-T), 인용 가능한(citable) 출처 만들기
  - 각 AI 엔진에 우리 브랜드 노출 **샘플 질의 모니터링**(월간 추적)
  - 사업화: GEO 자체가 다른 학원 대상 **컨설팅 상품** 후보
- **수익·성과 계획(KPI):** 타깃 질의 시 브랜드 인용률 / AI 경유 유입·문의(정성+샘플 추적). *측정이 어려운 신영역이므로 "월간 질의 리스트 모니터링"으로 베이스라인부터.*
- **실행:** 월 타깃 질의 20개 리스트 점검 + citable 콘텐츠(FAQ·정의형 글) 생산(블대리와 연계).

## 보고 체계 (대표 지시)
1. **담당 → 마팀장 (매일):** 그날 한 일·핵심 수치·다음 할 일 3줄.
2. **마팀장 → 클부장 (매일 상세):** 4담당 취합 → 신호등·병목·이번 주 초점 → **매일 데일리 루틴**으로 발행(콘텐츠 로그 반영).
3. **승인 게이트(즉시 실행):** 담당의 괜찮은 아이디어·기획은 마팀장이 클부장 경유 **대표께 1줄 제안** → **대표 승인 시 지체 없이 실행**(완벽보다 물길). 승인 결정은 의사결정 로그 기록.

## 성과 측정 (공통)
- 정본: **콘텐츠 발행·성과 로그 DB**(`81d1a75d…`) — 발행마다 채널·담당·유입·상담 기입.
- 월 1회 담당별 KPI 리뷰 → 잘 되는 채널에 자원 집중(80/20).
