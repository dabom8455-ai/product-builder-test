# 네이버 블로그 → 맘카페 상담전환 글쓰기 SOP — ② 마케팅팀 **1순위**

> 지시: 대표(원장) · 2026-09-09 · 실행: ② 마케팅팀 · 총괄: 클부장
> **마케팅 1순위 = 매일 네이버 블로그 1개 발행 → 우리동네 맘카페 게시 → 초등맘 상담 전환.**
> 유튜브·GEO·스레드는 **2순위로 하향**(블로그가 궤도에 오른 뒤 병행).

---

## 1. 목표 (한 줄)
**용인 모현/처인 지역 초등 저학년 엄마**가 글을 읽고 *"우리 아이도 피아노 시켜야겠다 → 도현피아노에 상담해봐야지"* 마음이 들게 한다.

- 성공지표: 블로그 유입 → **상담 문의 건수**(리드). 글 하단 CTA·전화·위치 클릭.
- 흐름: **네이버 블로그에 글 작성 → 우리동네 맘카페(네이버 카페)에 정보·후기 형태로 공유.**

## 2. 타깃 독자 & 톤
- **타깃:** 초등 1~4학년 자녀를 둔 지역 엄마. "사교육 뭐부터? 피아노 시켜도 될까? 어디가 좋지?"를 고민.
- **톤:** 광고가 아니라 **같은 동네 엄마의 진심 어린 정보/경험담**. 1인칭 공감체. 존댓말, 따뜻하게. **광고 티가 나면 맘카페에서 외면·삭제됨.**

## 3. 글 유형 (매일 로테이션)
| 요일감 | 유형 | 예 |
|------|------|----|
| 공감 | 엄마 고민 공감 | "피아노 학원 언제 보내야 할까요? 초1 엄마의 고민" |
| 정보 | 교육 정보 | "피아노가 초등 두뇌·집중력에 좋은 진짜 이유" |
| 실용 | 학원 고르는 법 | "좋은 피아노 학원 고르는 체크리스트 5" |
| 후기 | 우리 학원 이야기 | "요즘 아이들이 피아노를 다시 좋아하게 된 이유(도현피아노 일상)" |
| 지역 | 동네 육아 | "용인 모현읍 초등 예체능, 뭐가 있을까?" |

## 4. 글 구조 템플릿 (복붙용)
```
[제목] 공감·궁금증 유발 + 지역/키워드 (예: "초1 피아노, 시켜 말어? 용인 모현 엄마의 고민")

1) 공감 도입(3~4줄): 엄마라면 다 하는 고민을 내 이야기처럼. "저도 그랬어요…"
2) 본문(정보·경험 3~4단락): 왜 피아노인가 / 이 시기 아이에게 어떤 도움 / 흔한 오해 / 실제 변화
3) 사례·장면(1단락): 아이가 스스로 치고 싶어 하는 순간, 작은 성취. (구체적 장면 = 신뢰)
4) 부드러운 안내(CTA): "혹시 고민되시면 상담만 받아보셔도 좋아요." + 도현피아노 위치·전화·무료 상담
5) 해시태그: #용인피아노학원 #모현읍피아노 #처인구피아노 #초등피아노 #피아노학원추천
```

## 5. 상담 전환 장치 (매 글 필수)
- 글 끝 **부드러운 CTA 1개**: "무료 상담 문의: 도현피아노 ☎ 010-5158-3613 · 경기 용인 모현읍 왕산로14 몬테로이 2단지 상가"
- **댓글 유도 질문** 1개: "우리 아이 몇 살에 시작하셨어요?" → 댓글·소통 = 카페 노출↑.
- **지역 키워드**(용인·모현·처인구 + 피아노)를 제목·첫 문단·해시태그에 자연스럽게(GEO/검색).

## 6. 맘카페 게시 주의 (컴플라이언스)
- 카페마다 **홍보 규정이 다름** → 반드시 **정보·후기형**으로. 노골적 광고/도배 금지(강퇴·삭제 위험).
- 등업·게시판 규정 준수. 상업 홍보 게시판이 따로 있으면 그곳 우선.
- **금지:** 과장·허위 효능, 타 학원 비방, 원생/학부모 개인정보 노출.

## 7. 발행 흐름 (매일)
1. **매일 [자동] 클부장이 오늘의 글 초안 생성**(유형 로테이션 + 소재 뱅크) → 저장소 기록.
2. 원장 검토·개인 경험 한 스푼 추가 → **네이버 블로그 발행**.
3. **우리동네 맘카페**에 정보/후기 형태로 공유(규정 맞게).
4. 유입·상담 반응 관찰 → 잘 되는 유형 늘린다(피드백으로 고친다).

## 8. 소재 뱅크 (초기 10선)
1. 초1 피아노, 시켜 말어? / 2. 피아노와 집중력·두뇌 / 3. 아이가 학원 가기 싫어할 때 / 4. 피아노 학원 고르는 체크리스트 / 5. 바이엘·체르니가 뭐예요? / 6. 연습 안 하는 아이, 어떻게? / 7. 몇 살에 시작이 좋을까 / 8. 발표회가 아이에게 주는 것 / 9. 매달 진도 리포트로 알게 된 우리 아이 / 10. 용인 모현 초등 예체능 지도.
