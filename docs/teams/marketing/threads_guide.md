# 스레드(Threads) 동반 작성 가이드 — 블로그 1글 = 스레드 1글

> 지시: 대표 · 2026-09-09 · 실행: ② 마케팅팀 · 총괄: 클부장
> **규칙: 블로그 글을 쓸 때마다 그 글을 기반으로 스레드 글 1개를 항상 함께 작성한다.**
> 기술 기초기: [`writing_playbook.md`](writing_playbook.md) §4-2 · 블로그 톤: [`blog_guide.md`](blog_guide.md).

---

## 1. 왜 블로그 + 스레드 세트인가
- **블로그(네이버)** = 검색 자산(오래 남아 유입). **스레드** = 빠른 도달·대화·팬 형성.
- 하나의 글감으로 두 채널 = **1소스 멀티유즈**(사람 시간 ↓, 노출 ↑).
- 스레드에서 관심 생긴 사람 → 프로필·블로그·상담으로 연결.

## 2. 핵심 원칙 — "블로그 요약이 아니다"
블로그를 500자로 줄이는 게 아니라, **블로그에서 '한 각도' 하나만 떼어** 독립된 스레드로 만든다.
- 블로그 = 여러 포인트를 차근차근. 스레드 = **가장 뾰족한 한 문장**으로 승부.
- 오늘 블로그가 '외워서 치는 습관'이라면 → 스레드는 그 한 각도만 깊게.

## 3. 스레드 글 구조 (기술)
1. **첫 문장 후킹** — 스크롤을 멈추게. 엄마 속마음·현장 대사·의외의 사실 한 줄.
   - 예: `"피아노 3년째인데 새 악보만 주면 손이 멈춰요."`
2. **본문(짧게, 3~6줄)** — 공감 → 원인/관점 → 우리 방식. 한 가지 가치만.
3. **대화 유도 질문 1개** — 진짜 답하고 싶은 질문(댓글 = 도달↑ = 다음 소재).
   - 예: `여러분 아이는 악보 보고 칠까요, 외워서 칠까요?`
4. 톤: 블로그와 같은 **따뜻한 1인칭**. 광고·하드셀 ❌. 이모지 1~2개.
5. 길이: 본문 **500자 이내**(핵심). 길면 블로그로 보낸다.

## 4. 글 구조 선택 (소재 맞게 — writing_playbook §3)
- 공감·문제해결형(주력) / 충격사실형(교육 상식 반전) / 비하인드형(학원 장면).

## 5. CTA·연결 (부드럽게)
- 스레드는 **관계·도달**이 목적. 매 글 "상담하세요" ❌.
- 자연스러울 때만: "더 자세한 얘긴 블로그에 적어뒀어요", 프로필로 유도.
- 상담/전화는 공감이 충분히 쌓인 글에서만 한 줄.

## 6. 사실 기준 (헌장·SOP 공통)
- 지어낸 숫자·성과·가짜 후기 금지. 일반 현상 서술("~하는 아이들이 있어요")은 OK.

## 7. 발행 흐름 (블로그와 동시)
1. [자동] 클부장이 블로그 초안 + **스레드 동반글**을 같은 초안 문서에 함께 생성.
2. 원장 검토 → 블로그 발행 → **스레드 발행**(같은 날/직후).
3. 스레드 댓글·반응 관찰 → 다음 글 소재로.

## 8. 주의
- 스레드는 해시태그를 블로그처럼 많이 달지 않는다(주제 태그 1~2개면 충분).
- 같은 문구 복붙 말 것 — 스레드는 블로그와 **다른 첫 문장**으로 시작.
