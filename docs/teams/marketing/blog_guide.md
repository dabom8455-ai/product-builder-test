# 도현피아노 블로그 보이스 가이드 (실전 톤 고정판)

## 1. 대표님 예시글에서 뽑은 "도현 목소리" (그대로 지킨다)
대표님 예시(“🎹 우리 아이, 피아노를 제대로 배우고 있는 걸까요?”)에서 추출:

1. **제목** — 이모지(🎹) + 엄마의 속마음을 **질문형**으로. "우리 아이, ~걸까요?"
2. **도입** — 엄마가 집에서 실제 보는 장면을 나열해 공감. (연습 안 함 / 악보 보고 치는지 외워 치는지 모름)
3. **"~하셨다면 편하게 상담받아보세요 😊"** — 초반에 가볍게 한 번, 부담 없이.
4. **✔️ 체크리스트** — 우리가 무엇을 지도하는지 4개 안팎. (악보 읽기 / 리듬·박자 / 손가락 번호·기본기 / 표현·음악성)
5. **교육 철학 한 단락** — "진도 빨리보다 **지금 아이에게 필요한 것 먼저, 기초부터 제대로**." 🎵
6. **남은 수업 타임 공개** — 요일별 실제 빈자리. (구체성 = 신뢰 + 행동 유도)
7. **상담 안내** — "저녁 6시 이후 예약제, 미리 연락 주시면 시간 맞춰 안내." 😊
8. **따뜻한 마무리** — "‘치는 것’에서 그치지 않고 음악을 이해하고 스스로 연주하도록 정성껏 지도." 💛
9. **마무리 정보** — 📍도현피아노학원 / 📩 문의 안내.

### 말투 규칙
- **존댓말, 1인칭, 같은 동네 엄마이자 선생님의 따뜻한 톤.** 광고 아님.
- 이모지: 🎹 🎵 😊 💛 ✔️ 📌 📍 📩 ▫️ 를 **과하지 않게**(문단당 0~1개).
- 짧은 문단(모바일). 줄바꿈 넉넉히.
- 단정·강요 ✗ ("무조건 우리 학원"), 부드러운 권유 ○ ("부담 없이 한번 확인해보세요").

## 3. 네이버 SEO 장치 (이 톤을 유지하면서)
- **제목 맨 앞 + 첫 100자**에 지역+키워드 자연스럽게(용인/모현/처인구 + 피아노). 스마트블록·검색 노출.
- 문단 **3줄 이하**, 체크리스트·📌 블록으로 가독성(모바일 80%).
- 글 끝 **댓글 유도 질문** 1개("우리 아이 몇 살에 시작하셨어요?") → C-Rank 소통 점수.
- 해시태그 지역 키워드 고정.

## 4. 절대 금지 (헌장·SOP 컴플라이언스)
- **지어낸 숫자·성과·가짜 후기 금지.** (예: "OO% 향상", 없는 원생 사례) — §writing_playbook 0 원칙.
- 과장·허위 효능, 타 학원 비방, 원생·학부모 개인정보 노출 금지.
- **남은 타임**은 반드시 원장이 발행 전 실제 빈자리로 확정(바뀌는 정보).
