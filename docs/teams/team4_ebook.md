# ④ 지식·콘텐츠 수익화팀 *(구 전자책·글쓰기팀 — 전략 브리프 #001로 재편, 2026-09-11 대표 승인)*

> **한 줄 임무:** 도현피아노의 검증된 노하우를 **"시스템 판매를 위한 콘텐츠 무기고"**로 만든다.
> 리드마그넷으로 원장 리드를 모으고, 템플릿·전자책으로 수익화하며, **해외 영어 콘텐츠**까지 생산한다.

이 팀은 회사의 **기억과 목소리이자 판매 퍼널의 탄약고**다.
전자책은 더 이상 단독 상품이 아니다(검색 수요 하향 확인, 브리프 #001 §1-2).
**시스템 판매의 미끼(리드마그넷)·설명서·무기**로 재정의한다.
재고 없고 마진 최고인 상품군이라는 강점은 그대로 — 타깃을 "판매 퍼널"에 맞춘다.

---

## 1. 책임범위 *(재편)*

- **국내 리드마그넷** — "혼자 운영하는 피아노학원 잡무 탈출 7단계 체크리스트" 등 → 원장 리드 수집(②마케팅·컨시어지 퍼널 연결)
- **국내 템플릿 팩** — 우리가 실제 쓰는 상담/진도리포트/블로그 루틴 템플릿 묶음(셋업 대행의 셀프 버전)
- **해외 영어 템플릿·콘텐츠** — "Piano Studio Automation Kit" (Gumroad) · 한국 사례의 영어 재포장
- ①운영팀·대표의 현장 노하우를 → **글/전자책/템플릿**으로 상품화, ②마케팅팀 **콘텐츠 원천** 공급
- 지식 상품 라인업(무료 리드마그넷 → 저가 템플릿 → 전자책 번들) 설계

## 3. 자동화 로드맵 (L0 → L2)

1. **L0:** 노하우 1개 주제를 골라 원장 인터뷰 → 손으로 초안 작성.
2. **L1:** 인터뷰 녹음 → 초안 자동 변환 → 사람이 퇴고하는 반자동 집필.
3. **L2:** 주제만 정하면 초안·편집·표지·변환까지 도는 **전자책 공장**.
   → 이 워크플로우 자체도 다른 창작자에게 팔 수 있는 상품 후보.

---

## 4. 산출물

- 완성 전자책·템플릿 → 판매 상품 (③수익화팀 가격)
- 무료 소책자·글 콘텐츠 → ②마케팅팀 (리드마그넷/소재)
- 표준화된 노하우 문서 → 회사 지식 자산

## 5. KPI

- 발간 전자책/템플릿 수, 판매량·매출
- 전자책 1권 제작 리드타임 ↓ (자동화 성숙도)
- 리드마그넷 다운로드 수 → 리드 전환
