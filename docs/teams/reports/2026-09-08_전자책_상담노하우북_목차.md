# [전팀장 보고서] 첫 전자책 「상담 노하우북」 목차 초안

> 작성: 전팀장 → 클부장·대표 · 2026-09-08 · 상태: 🟡 제안(목차 승인 대기)
> 방식: 조사 → 검토 → 기획 → 제안 (팀 운영지침 §3)

---

## 📋 한 줄 요약
> 첫 전자책 주제를 **「상담 노하우북」**으로 확정 제안. 우리가 방금 인터뷰로 발견한 **1등 문제(상담→등록 전환)**를 정면으로 다루므로, **판매 검증이 가장 빠르고** 우리 학원의 실제 경험이 그대로 콘텐츠가 된다.

---

## 1. 조사 (Research)
- 1차 인터뷰 발견: 원장의 최대 고민 = **"상담이 등록으로 안 이어짐."** 이건 **모든 소규모 학원 원장의 공통 통증**일 가능성이 높다.
- 기존 대안 전무(후속 관리 도구·노하우 없음) → 이 주제의 **수요가 크다.**
- 우리는 이미 [상담 후속 관리 키트](../../mvp/consult_followup_kit.md)와 [문제 파악 인터뷰 메타스크립트](../../playbook/metascript_problem_interview.md)라는 **원천 자료**를 보유.

## 2. 검토 (Review)
- 《린 스타트업》: **가장 잘 아는 것부터.** 우리가 직접 겪고 검증 중인 문제 = 가장 진짜인 콘텐츠.
- ①학원운영팀의 상담·후속 자산과 직접 연결 → 팀 간 선순환(①→④).
- 전자책은 재고 없고 마진 높은 상품 → 첫 수익 실험으로 적합.

## 3. 기획 (Plan) — 목차 초안 (v0.1)

**제목(가안):** 『상담이 등록으로 이어지는 법 — 1인 학원 원장을 위한 상담·후속 실전 노하우』

| 장 | 제목 | 핵심 내용 |
|---|------|-----------|
| 0 | 들어가며 | "왜 상담은 잘 봤는데 등록이 안 될까" — 원장의 진짜 고민 |
| 1 | 상담 전 준비 | 문의 응대 첫 30초, 방문 예약 잡는 법, 준비물 |
| 2 | 상담 중 대화 | 학부모가 진짜 궁금한 것, 커리큘럼 설명법, 신뢰 쌓기 |
| 3 | **등록으로 잇는 후속** ⭐ | 상담 후 2일의 법칙, 후속 문자 템플릿, 밀어붙이지 않고 돕기 |
| 4 | 놓치지 않는 시스템 | 상담자 기록·후속 관리(우리 후속 키트 방식) |
| 5 | 후속 자동화 맛보기 | 반복을 줄이는 자동화(우리 MVP 이야기) |
| 부록 | 바로 쓰는 템플릿 모음 | 문자·안내문·체크리스트 |

- **리드마그넷(무료 소책자):** 3장 「후속 문자 템플릿 5종」만 뽑아 무료 배포 → 인스타·홈페이지에서 이메일/연락처 수집 → ② 마케팅 리드.

## 4. 제안 (Propose) — 대표 결정 필요 ⭐
1. **주제(상담 노하우북)·목차 v0.1 승인**하시겠습니까?
2. 집필 원천은 **원장님의 실제 경험**입니다 → 전팀장이 **원장 인터뷰(집필용)**로 3~5장 내용을 캐도 될까요?
3. 무료 소책자(리드마그넷) 먼저 만들어 **채널 테스트**부터 하는 것 어떠세요? (린: 작게 검증)

## 5. KPI
- 목차 확정 → 리드마그넷 다운로드 수 → 전자책 판매 수·매출

## 6. 실행 (승인 시)
- [ ] 목차 확정 → 3장(후속) 먼저 집필(우리 키트 기반, 이미 자료 있음)
- [ ] 리드마그넷 "후속 문자 템플릿 5종" 제작 → ②마케팅과 배포
- [ ] 원장 집필 인터뷰 일정
