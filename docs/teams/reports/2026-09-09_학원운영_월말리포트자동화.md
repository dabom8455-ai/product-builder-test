## 3. 업무 루틴 (확정)
```
매월 25일  → [자동] 원장에게 입력 리마인드
~25일      → 원장: 학생별 4줄 입력(노션 DB/구술) + 영상 촬영
25일 즉시   → 클부장/AI: 원생 전원 리포트 자동 생성 → DB 기록 → 원장 검토
25일~말일  → 원장: 카톡 발송(영상 첨부) → 발송여부=발송완료
말일       → 클부장: 발송률 집계·보고
```
- **누락 0 원칙:** 전원 생성될 때까지 미입력 학생을 되짚음.

## 4. 자동화 수준
- 현재 **L1 = 생성 자동화**(원장의 '글 쓰는 시간' 제거). 입력·발송은 원장.
- L2(추후) = 진도 데이터 누적 시 초안 자동 + 카카오 알림톡 API 연동 시 **발송까지 자동** → **B2B 판매 상품**.

## 5. 효과 (기대)
- 원장 시간 절감: 학생 1명 리포트 작성 5~10분 → **입력 30초**. 원생 28명 기준 월 2~4시간 절감 추정.
- 학부모 신뢰·재등록률·차별화(경쟁 학원 대비 정기 소통).

## 6. 남은 것 / 대표 확인
- **이번 달(9월) 첫 실전:** 9/25 리마인드 시 원장 입력 → 전원 생성 테스트.
- (선택) 지금 1명분 실입력으로 품질 사전 확인 가능.
- L2 자동 발송은 카카오 알림톡(비즈니스 채널) 개설 검토 필요.
