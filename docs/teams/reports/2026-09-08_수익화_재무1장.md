# [수팀장 보고서] 학원 재무 1장 틀 + 데이터 요청

> 작성: 수팀장 → 클부장·대표 · 2026-09-08 · 상태: 🟡 제안(대표 데이터 입력 대기)
> 방식: 조사 → 검토 → 기획 → 제안 (팀 운영지침 §3)

---

## 📋 한 줄 요약
> "지금 우리가 버는 구조"를 **숫자 한 장**으로 확정한다. 이 숫자가 있어야 가격·마케팅·자동화 투자 판단의 근거가 선다. **대표님이 6개 숫자만 채워주시면** 손익·손익분기·원생당 이익이 자동으로 나온다.

---

## 1. 조사 (Research)
- 현재 아는 것: 원생 **약 24명**, 원장 **1인** 운영, 운영시간 13:00~18:00.
- 모르는 것: 매출 규모, 수강료 단가, 고정비(임대료·관리비), 변동비(교재 등), 순이익.
- 원장 1인 구조라 **원장 인건비 = 기회비용**으로 따로 인식해야 실제 수익성이 보인다.

## 2. 검토 (Review)
- 《린 스타트업》: **정밀 예측 대신 페르미 추정** — 대략의 숫자로 빠르게 사업성부터 본다.
- 완벽한 회계가 목적이 아니라, **"원생 몇 명이면 남는가(손익분기)"**를 아는 게 목적.

## 3. 기획 (Plan) — 재무 1장 구조
아래 **입력 6칸**만 채우면 나머지는 계산된다.

### 입력 (대표님이 채울 값)
| # | 항목 | 값 |
|---|------|-----|
| A | 현재 원생 수 | 24 (확인됨) |
| B | 원생 1인당 평균 월 수강료 | [입력] 원 |
| C | 월 임대료 | [입력] 원 |
| D | 월 관리비·공과금(전기·수도·인터넷 등) | [입력] 원 |
| E | 월 기타 고정비(피아노 리스·보험 등) | [입력] 원 |
| F | 월 변동비(교재·행사·소모품 등) | [입력] 원 |

### 자동 계산 (틀)
- **월 매출** = A × B
- **월 총비용** = C + D + E + F
- **월 순이익(원장 인건비 전)** = 매출 − 총비용
- **원생 1인당 기여이익** = B − (F ÷ A)
- **손익분기 원생 수** = (C+D+E) ÷ (B − 변동비단가) → *"몇 명부터 흑자인가"*

## 4. 제안 (Propose) — 대표 데이터 입력 필요 ⭐
> 위 **B~F 5개 숫자**만 알려주시면(대략도 OK), 클부장이 재무 1장(노션/시트)을 완성해 손익·손익분기를 보고드립니다.
- 정확히 몰라도 됩니다 — **어림값**이면 충분합니다(페르미 추정).
- 채워지면 → **⑥ 수강료·⑦ 매출 DB 개설**로 연결해 매달 자동 집계 구조로 확장.

## 5. KPI
- 월 순이익률 · 원생당 기여이익 · 손익분기 원생 수 · 목표 원생 수까지의 여유

## 6. 실행 (데이터 확보 후)
- [ ] 재무 1장 완성(입력→손익 자동)
- [ ] 손익분기·목표 원생 수 산출 → 마케팅 목표(리드 수)와 연결
- [ ] ⑥⑦ 재무 DB 개설 제안
