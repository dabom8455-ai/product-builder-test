# 🔧 온보딩 & 세팅 SOP (수동 복제판) — 셋대리용

> 자산 B · 클부장 2026-09-12 · GAP-6·G7·G8 해소.
> **전략(G7 결정):** 첫 고객~5명까진 **수동 복제**로 세팅한다(견인 우선). 멀티테넌트 자동화는 고객 3~5명 시점에 착수. 완벽보다 물길.
> 목표 SLA: **결제 후 영업일 5일 내 Go-live.**

## 1. 온보딩 폼 (결제 직후 고객에게 발송 — 이것만 받으면 됨)
- [ ] 학원명 / 원장 성함 / 연락처 / (희망) 도메인·서브도메인명
- [ ] 수업 요일·타임(빈자리 포함)
- [ ] 수강료·수업 횟수·결제일
- [ ] 입금 계좌(대시보드 안내용)
- [ ] 현재 원생 명단(선택 — 있으면 이관, CSV/엑셀/사진 무엇이든)
- [ ] 노션 사용 여부(백업 연결용 토큰은 세팅 미팅 때 함께)

## 2. 세팅 체크리스트 (셋대리 실행 순서)
1. [ ] 고객 전용 **대시보드 인스턴스** 생성(서브경로/도메인) + **DASHBOARD_PIN** 발급·전달(안전 채널).
2. [ ] 대시보드 메뉴 활성화: 원생·상담·일정·진도·매출·입금.
3. [ ] **자동화 루틴 ON** — ①상담 예약·리마인드 ②월말 진도 리포트 초안 ③미입금 알림.
4. [ ] **노션 백업 연결**(고객 노션 토큰·DB ID·PIN 3종 env) — 우리가 겪은 그 절차 그대로 안내.
5. [ ] 원생 데이터 이관(있으면) → 오등록·중복 검수.
6. [ ] 홈페이지 기본 정보(상호·주소·전화·타임) 고객 확정본으로 입력.
7. [ ] 웹 URL 레지스트리에 고객 인스턴스 1줄 기록(내부 관리).

## 3. Go-live 인수 확인 (고객이 직접 1회씩 성공)
- [ ] 상담 예약 1건 넣기 → 리마인드 자동 발송 확인.
- [ ] 진도 1건 기록 → 월말 리포트 초안에 반영됨 확인.
- [ ] 입금 1건 등록 → 대시보드 반영·미납 알림 확인.
- [ ] 고객 "이제 혼자 할 수 있다" 확인 서명(간단 회신) → **납품 완료**.
- [ ] 성대리에게 인계(30일 체크인 예약).

## 4. 사용 가이드 (고객에게 함께 전달 — GAP-8)
1페이지 요약 + 3개 짧은 안내:
- **상담 받기:** 일정 관리 → 예약 추가(리마인드는 자동).
- **진도 남기기:** 진도 관리 → 학생 선택 → 오늘 진도 한 줄. (월말 리포트가 알아서 모음)
- **입금 보기:** 입금 관리 → 미납 빨간 표시 확인.
> "매일 3번의 클릭이면 끝. 나머지는 시스템이 합니다."

## 5. 다고객 운영 주의 (보대리와 공유)
- 업데이트 배포 시 **회귀 테스트** 후 반영. 고객별 커스텀 값(상호·타임) 덮어쓰지 말 것.
- 롤백 경로 확보. 장애 시 SLA(영업일 1일 내 1차 회신)로 보대리 대응.
