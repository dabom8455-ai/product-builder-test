## 도현컴퍼니가 [ 원장님 학원 ]에 제안드립니다

**원장님이 꼽으신 가장 큰 잡무 3가지**
1. [ 상담 예약 왔다갔다 ]
2. [ 매달 진도 정리해 학부모께 보내기 ]
3. [ 수강료 입금 확인·미납 관리 ]

**→ 이 셋을, 저희가 우리 학원에서 실제로 없앤 그대로 원장님 학원에 깔아드립니다.**

> 💡 **기계치도 괜찮아요 — 매일 클릭 3번이면 끝.** 나머지는 시스템이 합니다.

| 잡무 | 자동화 후 |
|---|---|
| 상담 예약 | 온라인 접수→**자동 예약·리마인드**. 놓치는 문의 0 |
| 진도 공유 | 매 수업 기록→**월말 리포트 자동 초안**. 클릭 한 번 발송 |
| 입금 관리 | 대시보드에서 **입금·미납 한눈에**, 미납 자동 알림 |

### 무엇을 드리나
- 원장님 학원 전용 **홈페이지 + 운영 대시보드**(원생·상담·일정·진도·매출·입금).
- **자동화 루틴** 세팅 + 데이터 이관 + **1:1 사용 교육**.
- 노션 백업 연결(데이터는 원장님 것, 언제든 내보내기).

### 가격
- **컨시어지 셋업 39만원**(1회) — 저희가 직접 세팅·이관·교육.
- **유지보수 월 3.9만원** — 호스팅·업데이트·기술지원·CS. (연납 시 2개월 무료)

### 원장님의 리스크 = 0
> **2주 안에 위 3기능이 실제로 안 돌아가면 셋업비 전액 환불.** 구독은 언제든 해지, 위약금 없음.

### 왜 도현컴퍼니인가
저흰 **직접 1인 학원을 운영하며** 이 시스템을 매일 씁니다. 파는 사람이 아니라 **같은 문제를 먼저 푼 사람**이 깔아드립니다.
