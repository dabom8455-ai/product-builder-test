## 운영 메모
- **보고·브리핑 루틴은 모두 "이 세션 연결(persistent)" 방식이다.** 새 세션 방식은 저장소 push 권한이 없어 결과가 소실되므로 쓰지 않는다. 이 세션으로 들어와 실행→repo·노션 기록→보고한다.
- 발행 방식 차이: 세션연결 루틴은 claude.ai 열면 이 대화에 바로 뜬다(별도 휴대폰 푸시 알림은 약할 수 있음).
- 조정/중지: 대표님이 "○○ 루틴 주 O회로/꺼줘" 하시면 클부장이 반영.
