> 상품: 1인학원 운영 자동화 패키지(운영 대시보드 중심) · 셋업 39만 / 월 3.9만 / 2주 성과보증.

## 1. 문의 접수 ✅
🗣️ [구글폼] "도현피아노 이보나입니다. 1인 운영인데 상담·진도·입금 관리가 손이 많이 가요. 자동화 가능할까요?"
⚙️ CRM에 1호 리드 생성(업종=피아노/1인/유입=자체 파일럿).
> ⚠️ **가감없는 조언:** 1호가 '우리 자신'이라 진짜 시장검증은 아니다. 이 딜리버리는 **런북을 단단히 만드는 용도**로 쓰고, **2호=실제 외부 원장**을 최대한 빨리 잡아야 진짜 피드백이 나온다. (→ 2호 확보를 마케팅 최우선 과제로.)

## 2. 상담·안내 ✅
진단 스크립트(`sales_diagnostic_script.md`)대로 잡무 3종(상담·진도·입금) 합의 → 제안서 제시 → "매일 클릭 3번 + 2주 전액환불" 안심.

## 3. 구매 결정 ✅
상품 범위 = **운영 대시보드 중심**. 셋업 39만 / 월 3.9만 확정. 계좌이체+세금계산서.
> ⚠️ **조언:** 우리 자신이 고객이므로 결제는 '장부상 내부거래'로 처리(재팀장, B부문). 실제 현금흐름 아님을 회계에 명시.

## 4. 학원 자동화 세팅 🔄 (셋대리)
**결정(가감없는 조언 반영):** 도현피아노 사이트는 **이미 라이브**(https://dohyeon-piano.netlify.app + 대시보드 + 노션 백업 성공). 따라서 1호는 **별도 사이트 신설이 아니라 기존 라이브 인스턴스를 '1호 고객 인스턴스'로 확정**한다. (신규 사이트 프로비저닝 리허설은 2호 때 실제로 한다 — 그게 진짜 테스트.)
세팅 점검:
- [x] 사이트 라이브 · [x] DASHBOARD_PIN 설정 · [x] 노션 백업 연결 성공
- [ ] **샘플 데이터 비우기**(샘플 학생1~3 → 실제 원생으로 교체) ← 5단계
- [ ] 자동 백업 ON 확인

## 5. 고객 입력값 요청서 ⏸️ (대표가 라이브 대시보드에 입력)
> 아래를 https://dohyeon-piano.netlify.app/dashboard 에서 입력. (PIN 필요)

**(1) 학원 정보** — 설정(마이) 화면
- 학원명 `도현피아노` / 원장 `이보나` / 주소·전화(확정본) / 운영시간 / **기본 교습비** [대표 입력]

**(2) 실제 원생** — 원생 관리 (★ 먼저 '전체 비움'으로 샘플 삭제)
- 각 원생: 이름·학년·요일·시간·교재·상태(재원/체험/휴원)·납부(완납/미납)·교습비·시작일 [대표 입력]

**(3) 이번 주 일정** — 일정 관리
- 실제 상담·발표회·휴원 등 [대표 입력]

**(4) 9월 매출·입금** — 매출/입금 관리
- 원비 수입·지출 실제값 [대표 입력]

**(5) 자동 백업** — 시스템 설정
- 자동 백업 **ON** 확인(이미 연결됨).

> ⚠️ **가감없는 조언(중요):** 대시보드 데이터는 **이 브라우저에만** 저장된다(단일 기기). 실입력 전에 **자동 백업 ON + 가끔 '내보내기(JSON)'** 를 습관화. 외부 판매 전, '자동 백업 기본 ON·복구(Import) 버튼 강조'를 홈팀장에게 개선 요청할 것(아래 반영 목록).

## 6. 자동화 실행 확인 ⏸️ (대표가 라이브에서 1회씩)
- [ ] 상담 1건 등록 → (예약·리마인드 동작 확인)
- [ ] 진도 1건 기록 → 월말 리포트에 모이는지
- [ ] 입금 1건 등록 → 미납 빨간 표시
- [ ] 자동 백업 1회 → 노션에 백업 페이지 생성 확인
→ 4개 성공 시 **1호 납품 완료(검수 통과)**.
