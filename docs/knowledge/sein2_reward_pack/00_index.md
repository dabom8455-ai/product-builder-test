## 팀별 적용 가이드 (클부장 지시)

### ② 마케팅팀 — 최우선 활용 ⭐
- **매일 블로그+스레드 100건 프로젝트의 프롬프트 엔진으로 `templates.md`를 쓴다.**
  - 블로그 글: `templates.md` → **블로그 12선**(리스티클/비교분석/개인경험담/개념설명/뉴스레터형 등)에서 그날 유형을 골라 골격을 뽑고, 우리 `writing_playbook.md`의 후킹·CTA로 마감한다.
  - 스레드: **쓰레드 12선**(바이럴 후킹/공감 서사/권위·고가치 정보)에서 골라 블로그 동반 스레드를 만든다.
  - 인스타/릴스: **인스타그램 12선**에서 피드·스토리·릴스 유형별로.
  - 이메일: 향후 뉴스레터·상담 리마인드에 **이메일 12선**.
- **적용 규칙:** 프롬프트의 `[대괄호]` 자리표시자에는 반드시 **도현피아노 실제 정보**(모현읍·초등 피아노·악보 읽기 중심 커리큘럼)를 넣는다. 세인투 예시(부동산 등)는 우리 맥락으로 치환한다.
- 2권(글쓰기 자동화)·3권(퍼스널 브랜딩)은 원장님 개인 브랜딩·채널 기획 시 참고.

### ④ 전자책·글쓰기팀 — 핵심 자산 ⭐
- **`ebook4.md`(30일 전자책 출판)** 를 우리 전자책 상품(커리큘럼·상담노하우) 제작의 **공정 템플릿**으로 삼는다: 기획 → 목차 → 집필 → 표지/상세페이지 → 판매까지 프롬프트로 초안.
- `ebook3.md`(수익화)로 전자책 가격·번들·업셀 설계 아이디어를 얻는다.

### ③ 수익화팀
- `ebook3.md`의 수익화 모델·가격 책정·성장 로드맵 프롬프트를 **재무 시나리오·객단가 설계**에 참고.
- `tools.md`로 **무료/저가 도구 조합**을 골라 자동화 비용을 낮춘다(월 고정비 최적화).

### ① 학원운영팀
- `tools.md`의 TTS·이미지 도구로 **안내문·수업 자료·학부모 공지** 제작 자동화.
- `ebook1.md`(에이전트 활용)로 반복 운영 업무 자동화 프롬프트 참고.

### 클부장(총괄)
- 데일리 인텔 브리핑·문서 작성 시 `ebook1.md`(프롬프트 설계법)를 표준으로 참고.
- 신규 과업마다 "이 일에 적용할 리워드 자산이 있나?"를 먼저 점검한다.

## 사용 원칙 (중요)
1. **치환 필수:** 모든 프롬프트의 예시·자리표시자는 도현피아노/도현컴퍼니 맥락으로 바꾼다.
2. **검증 후 발행:** AI 초안은 반드시 담당 팀장 검토 → 클부장 검토 후 외부 발행.
3. **도구는 공식 사이트에서 최종 확인:** `tools.md`의 요금·무료량은 2026.09 기준, 변동될 수 있다.
4. **저작권:** 원문은 학습용. 프롬프트 구조는 활용하되 세인투 문장을 그대로 복제해 재판매하지 않는다.
