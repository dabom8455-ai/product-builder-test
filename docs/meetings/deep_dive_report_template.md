# 각 담당 직접 심층보고 — 표준 양식 (사업회의용)

> **개편 지시 (대표, 2026-09-12):** 사업회의에서 **클부장 요약 대신 각 담당이 직접 심층보고**한다.
> 클부장은 이제 *퍼실리테이터*로서 순서를 돌리고 시간을 지키며, **내용은 각 담당 본인이 발표**한다.
> 보고 3축은 고정: **① 진행사항 · ② 앞으로의 계획 · ③ 수익화 아이템 개발현황.**

---

## 1. 심층보고 양식 (모든 담당 공통 · 1인당 2분, pre-read는 이 양식대로 글로 먼저)

```
【담당: ○○ (예: 블대리 · 블로그)】  신호등 🟢/🟡/⚪/🔴

① 진행사항 (지난주 실제로 한 것)
   - 무엇을 했나 (행동 1~3개, 완료/진행중 표시)
   - 숫자 (조회·리드·전환·매출 등 / 실데이터 없으면 "입력 대기")
   - 배운 것 1줄 (가설 검증 결과)

② 앞으로의 계획 (이번 주 + 다음 단계)
   - 이번 주 착수할 단 1가지 (오늘/이번 주 실행 가능한 것)
   - 그 다음 수 (2~3주 시야)
   - 필요한 지원 / 대표 결정 대기 (있으면)

③ 수익화 아이템 개발현황 (★ 대표 최우선 관심)
   - 내 담당이 만드는 '팔 수 있는 것'은 무엇인가
   - 지금 단계: [아이디어 → 기획 → 초안 → 검증 → 판매] 중 어디
   - 병목 1개 + 이번 주 넘길 다음 액션 1개
```

> **원칙(사업회의 헌법 준수):** 근거로 말한다(HiPPO 금지) · 숫자 없으면 "입력 대기"(지어내지 말 것) · 강한 의견 느슨한 확신 · 완벽보다 물길.

## 3. 진행 순서 (클부장=퍼실리테이터)
1. **사전자료 침묵독서 5분** — 각 담당이 위 양식대로 올린 글을 다 같이 읽음.
2. **라운드로빈 심층보고** — §2 순서대로 1인 2분씩 **본인이 직접**. 클부장은 시간만 관리, HiPPO(대표)는 마지막에.
3. **수익화 집중 토론** — ③축(수익화 아이템)만 모아 A팀 제안·B팀 레드팀.
4. **결정(DACI)·액션(DRI)** — 이번 주 최우선 3 + 담당·기한.
5. **회의록** → `docs/meetings/minutes/` 저장 + 의사결정 로그 DB 기록.
