# [⑥ 전략기획실] 홈페이지 역설계 분석 + 우리 페이지맵

> 참고 사이트: 클래스101(class101.net) 류 **설득형 판매 랜딩** 패턴.
> ※ 라이브가 SPA라 코드 추출은 제한적 → 아래는 이 아카이브형 랜딩의 **검증된 표준 구조**를 역설계한 것 + 우리 판단.
> 원칙: **패턴만 배우고 디자인·브랜드는 도현피아노 오리지널.** (복제 아님)

## 1. 역설계 — 잘 되는 판매 랜딩의 뼈대 (왜 잘 되는가)

설득형 랜딩은 **"방문자의 마음이 움직이는 순서"**대로 섹션을 놓습니다.

| 순서 | 섹션 | 목적(설득 논리) | 기법 |
|:---:|------|-----------------|------|
| 1 | **히어로** | 3초 안에 "이게 나한테 뭔데?" | 한 문장 약속 + 단 하나의 CTA + 신뢰 한 스푼(숫자) |
| 2 | **공감(문제)** | "맞아, 내 얘기야" | 고객의 고통을 그대로 언어화 |
| 3 | **해결(방법)** | "이렇게 풀리는구나" | 우리만의 방식(차별점)을 그림처럼 |
| 4 | **증거(신뢰)** | "진짜네" | 후기·성과·숫자·전문성 (사회적 증거) |
| 5 | **오퍼(제안)** | "이걸 받고 싶다" | 명확한 혜택 + 지금 해야 할 이유 |
| 6 | **가격·결제** | "이 값이면 하지" | 티어·비교·리스크 제거(환불/무료체험) |
| 7 | **FAQ + 최종 CTA** | 마지막 망설임 제거 | 반대 의견 선제 답변 + 다시 CTA |

**핵심 기법 5가지 (우리도 쓴다):**
1. **CTA 반복** — 스크롤 내내 같은 행동(문의/구매)을 여러 번 제안.
2. **사회적 증거** — 후기·수강생 수·성과 그래프로 "남들도 한다".
3. **손실 회피** — "지금 안 하면 놓치는 것"(이번 달 자리·혜택).
4. **스토리** — 기능 나열이 아니라 "아이가 이렇게 큰다"는 이야기.
5. **한 번에 한 행동** — 페이지마다 주행동 하나로 좁힌다.

## 2. 우리 페이지맵 (1차 초점: 문의 전환 + 전자책 결제)

### 홈(랜딩) 섹션 순서 — 위 뼈대에 우리 비전을 입힘
1. **히어로** — "피아노에 집중합니다. 나머지는 AI가." + **[무료 상담 신청]** + 위치·전화
2. **공감** — "상담은 봤는데 등록이 망설여지시죠? / 우리 아이에게 맞을까?" (학부모 고민 언어화)
3. **해결 = 우리 방식** — "운영은 AI가, 교육은 선생님이" → 맞춤지도·투명한 진도·끊김없는 소통
4. **커리큘럼** — 유아/기초/심화/입시 4단계
5. **증거** — 원생 후기·연주 영상·성장 사례 *(수집 전까지 [준비 중] 표시)*
6. **AI 자동화 강점(차별점)** — 상담 자동응대·출결/진도 자동관리·**학부모 월간 리포트**(Idea Bank 발굴 기능)
7. **상담 문의 폼** ⭐ — 이름·연락처·아이 나이·문의내용 → **① 리드 DB** (전환의 핵심)
8. **전자책 코너** — 「상담 노하우북/무료 소책자」 소개 + **결제/다운로드** (전자책 초안 연계)
9. **푸터** — 연락처·인스타·네이버·운영시간

### 별도 페이지
- **상담 예약/문의** (폼 상세) · **전자책 상세·결제** · (미래) **자동화 시스템 소개(B2B)**

---

## 3. 각 팀 유기 협조 (누가 무엇을 채우나)
> 홈페이지 하나에 전 팀이 물린다. 이게 "회사 비전이 녹아든 사이트"의 실체.

| 섹션/기능 | 담당 팀 | 대는 것 |
|-----------|---------|---------|
| 전체 카피·구축·후기 수집 | ② 마케팅 | 문구, 노코드 구축, 유튜브/인스타 연동 |
| 커리큘럼·상담폼→리드 연결 | ① 학원운영 | 과정 설명, 상담 응대 흐름 |
| 전자책 코너 상품 | ④ 전자책 | 소책자·전자책 콘텐츠 |
| 가격·결제 정책 | ③ 수익화 | 전자책 가격, 결제수단 |
| 차별 메시지·증거 논리 | ⑥ 전략기획실 | 경쟁 빈틈 기반 카피, RE 분석 |
| 폼 → 리드 DB 데이터 연결 | ⑤ 인프라 | 문의 데이터 표준·적재 |

---

## 4. 결제·플랫폼 권고 (③수익화 + ②마케팅)
- **전자책 결제:** 아임웹/식스샵 등 **디지털 상품 결제 지원 노코드**로 구축(즉시 결제·자동 다운로드).
- **상담 문의 폼:** 자체 폼 또는 네이버 폼 → **① 리드 DB로 수집.**
- **원칙(린):** 처음부터 완벽 쇼핑몰 X. **문의 폼 + 전자책 1개 결제**부터 열고 반응 보며 확장.
