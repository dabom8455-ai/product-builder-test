# 카페댐 (CafeDam) — 카페 운영 올인원 앱

기획서: [`../docs/PLAN.md`](../docs/PLAN.md)

## 배포된 앱

**https://claude.ai/artifact/DztAEwpTGpFLEe1RW91g2k** (claude.ai 아티팩트, 기본 비공개 — 공유는 페이지의 Share 메뉴에서)

- 데이터는 claude.ai 에 저장되어 휴대폰·태블릿·PC 어디서 열어도 같습니다(로그인 필요).
- 리뷰 답글·포스터 문구는 보는 사람의 Claude 계정으로 작성합니다(첫 사용 시 허용 요청). API 키가 필요 없습니다.
- 포스터 PNG·백업 JSON 은 저장 확인창을 거쳐 내려받습니다. 아티팩트에서는 인쇄 버튼이 숨겨집니다.

재배포: `npm run build:artifact` → `dist-artifact/cafedam.html` 을 같은 아티팩트 URL 로 다시 게시합니다.

## 로컬 실행

```bash
cd app
npm install
npm run dev        # http://localhost:3000
```

처음 열면 **샘플 카페 데이터**(메뉴 12종·재료 20종·8주 판매·알바 3명·리뷰 8건)가 들어 있어 바로 둘러볼 수 있습니다.
설정 → 데이터에서 “모두 지우고 시작”을 누르면 내 카페 데이터로 시작합니다.

### AI 기능 (선택)

`.env.example`을 `.env.local`로 복사하고 `ANTHROPIC_API_KEY`를 넣으면 리뷰 답글과 포스터 문구를 Claude가 작성합니다.
키가 없으면 내장 템플릿 생성기로 동작하므로 모든 기능을 키 없이 사용할 수 있습니다.

## 기능

| 화면 | 내용 |
|---|---|
| 홈 | 오늘·어제 매출, 14일 추이, 지난달 순수익, 오늘의 제안, 답글 대기 리뷰, 근무 중 직원, 원가율·노무 경고 |
| 메뉴·원가 | 재료 단가(이력 포함) → 레시피(서브레시피 지원) → 메뉴 원가·원가율·채널별 순마진, 목표 원가율 권장가, 재료 단가 변동 영향 시뮬레이션 |
| 매출 입력 | 일 마감(날짜×채널×메뉴 수량), POS/배달앱 CSV 가져오기, 고정비·월별 지출 |
| 손익 | 총매출 → 부가세 → 원가 → 수수료 → 인건비 → 고정·변동비 → 순수익, 손익분기점, 채널별 실질 마진, 세금 적립 가이드 |
| 메뉴 분석 | 메뉴 엔지니어링 매트릭스(Star/Plowhorse/Puzzle/Dog), 리뷰 연동 품질 경고, 가격 인상·판매중지·포스터 제작 원클릭 실행, 실행 전후 효과 추적 |
| 리뷰 답글 | 리뷰 붙여넣기 → 메뉴·감정·불만 키워드 분석 → 가게 말투로 답글 초안 → 복사·게시 완료 처리, 키워드 리포트 |
| 알바 근태 | 매장 태블릿 PIN 출퇴근, 근무 기록 수정, 법정 휴게 자동 차감, 주휴수당·(5인 이상) 연장·야간 가산, 공제, 임금명세서 인쇄 |
| 홍보 포스터 | 메뉴·목적·사이즈(피드/스토리/A4)·스타일 선택, 사진 업로드, 문구 추천, PNG 저장·공유. Puzzle 메뉴 자동 추천 |
| 설정 | 매장·브랜드색·답글 말투·과세유형·사업장 규모, 채널 수수료, 목표 원가율, 노무 기준(최저시급 등), 백업/복원 |

## 구조

```
src/
  lib/
    types.ts            데이터 모델
    domain/             순수 계산 로직 (단위 테스트 대상)
      cost.ts           원가·원가율·채널 마진
      payroll.ts        근무시간·휴게·주휴·가산·공제
      pnl.ts            월 손익·손익분기
      menuEngineering.ts 메뉴 매트릭스·조정 제안
      review.ts         리뷰 분석·답글 템플릿·AI 프롬프트
      poster.ts         포스터 문구
    store.ts            앱 상태(zustand)
    persistence.ts      저장 엔진 + 브라우저 저장소 어댑터 (어댑터만 바꾸면 저장 위치 변경)
    platform.ts         실행 환경별 기능(AI·파일 저장·인쇄) 주입 지점
    seed.ts             샘플 카페 데이터
    server/claude.ts    Claude API 호출 (서버 전용)
  app/                  화면 + /api/ai/{reply,copy}
  artifact/             claude.ai 아티팩트 빌드: 해시 라우팅, db 어댑터(월별 분할 저장), sample·downloads 플랫폼
scripts/build-artifact.mjs  단일 HTML 빌드 (React 18 UMD + 인라인 번들·CSS)
```

```bash
npm test        # 도메인 로직 테스트

```

## 현재 한계 (다음 단계)

- 로컬 실행(`npm run dev`) 버전은 데이터를 브라우저에만 저장합니다. 여러 기기 공유는 배포된 아티팩트 버전을 쓰세요.
- 알바 개인 폰 출퇴근(GPS·Wi-Fi 확인)은 아직 없습니다. 매장 태블릿 PIN 방식입니다.
- 네이버·배민 리뷰는 공식 답글 API가 없어 붙여넣기 방식입니다.
- 4대보험 요율·간이과세 부가세는 근사치입니다. 실제 신고 전 세무사·노무사 확인을 권장합니다.
